# 명령어

## 개인 소지금

`/gtvault money`와 `/소지금`은 같은 명령어입니다.

| 명령어                       | 권한                  | 설명                                    |
| ---------------------------- | --------------------- | --------------------------------------- |
| `/gtvault money`             | 없음                  | 내 소지금 보기                          |
| `/소지금 조회 <대상>`        | `gtvault.money.admin` | 소지금 보기                             |
| `/소지금 지급 <대상> <금액>` | `gtvault.money.admin` | 소지금 늘리기                           |
| `/소지금 차감 <대상> <금액>` | `gtvault.money.admin` | 소지금 줄이기. 0원 아래로 내려가지 않음 |
| `/소지금 설정 <대상> <금액>` | `gtvault.money.admin` | 소지금을 그 금액으로 바꾸기             |

- 대상은 닉네임이나 UUID입니다. 오프라인이어도 서버에 접속한 적이 있으면 됩니다.
- 금액은 0 이상의 정수입니다. `10,000`처럼 쉼표를 써도 됩니다.

:::note `/소지금` 명령어 자체에 `gtvault.money.admin` 권한이 걸려 있어서, 일반 플레이어는 `/소지금`을 아예 쓸 수
없습니다. 일반 플레이어가 자기 소지금을 보려면 **`/gtvault money`**를 쓰세요. :::

## 공용 지갑

모두 `gtvault.wallet.admin` 권한이 필요합니다.

| 명령어                               | 설명                                    |
| ------------------------------------ | --------------------------------------- |
| `/gtvault wallet create <이름>`      | 지갑 만들기. 처음에는 비활성, 잔고 0    |
| `/gtvault wallet enable <이름>`      | 활성화                                  |
| `/gtvault wallet disable <이름>`     | 비활성화                                |
| `/gtvault wallet delete <이름>`      | 삭제                                    |
| `/gtvault wallet list`               | 지갑 목록                               |
| `/gtvault wallet balance <이름>`     | 잔고 보기                               |
| `/gtvault wallet give <이름> <금액>` | 입금. 실행한 플레이어의 기여도에 더해짐 |
| `/gtvault wallet take <이름> <금액>` | 출금. 0원 아래로 내려가지 않음          |
| `/gtvault wallet set <이름> <금액>`  | 잔고를 그 금액으로 바꾸기               |
| `/gtvault wallet top <이름> [개수]`  | 기여 순위. 개수 기본 10                 |

- 지갑 이름은 공백 없이 한 단어이고, 64자까지 쓸 수 있습니다. 기본 설정에서는 대소문자를 구분하지 않습니다(`Event`와
  `event`는 같은 지갑).
- **비활성 지갑은 `give`, `take`, `set`이 막힙니다.** 먼저 `enable`하세요.
- 기여 순위는 `give`를 실행한 **플레이어** 기준입니다. 콘솔에서 입금하면 기여도에 들어가지 않습니다.

### 삭제 확인

잔고가 남은 지갑을 지우면 확인 메시지가 나옵니다. **10초 안에** 같은 명령어를 한 번 더 입력하면 삭제됩니다. 잔고가 0이면
바로 삭제됩니다.

지갑을 삭제하면 잔고와 기여 순위도 함께 사라집니다. 거래 로그에는 삭제 당시 잔고가 남습니다.
