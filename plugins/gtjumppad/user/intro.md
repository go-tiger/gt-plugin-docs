# GTJumpPad

밟으면 바라보는 방향으로 날아가는 **점프패드 블록**을 만드는 플러그인입니다. 관리자가 손에 든 블록을 점프패드로 등록하고
지급하면, 그 아이템으로 설치한 블록만 점프패드로 동작합니다.

## 주요 기능

| 기능           | 설명                                                                          |
| -------------- | ----------------------------------------------------------------------------- |
| 블록 등록      | 손에 든 블록을 이름, 로어, 인챈트, 커스텀 모델 데이터 그대로 등록             |
| 설치 위치 추적 | 지급받은 아이템으로 설치한 자리만 점프패드. 같은 재질의 일반 블록은 해당 없음 |
| 발사           | 바라보는 수평 방향으로, 고정된 각도와 속도로 발사                             |
| 낙하 피해 방지 | 발사 후 첫 착지의 낙하 피해를 막음                                            |
| 블록 보호      | 폭발, 불, 피스톤으로부터 보호. 부수면 점프패드 아이템이 그대로 나옴           |
| 효과           | 소리, 파티클, 액션바 문구                                                     |
| 월드 제한      | 지정한 월드에서만 동작                                                        |
