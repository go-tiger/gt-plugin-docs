# 사용하기

## 점프패드 블록 등록

1. 점프패드로 쓸 블록을 손에 듭니다. 이름, 로어, 인챈트를 미리 붙여 두면 그대로 유지됩니다.
2. `/gtjumppad set`을 실행합니다.

- 설치할 수 있는 블록만 등록할 수 있습니다.
- 수량은 1개로 저장합니다.
- `item.auto-lore`가 `true`면 `item.lore`의 안내 문구를 로어 끝에 붙입니다. 이미 같은 문구가 있으면 붙이지 않습니다.
- 등록은 하나만 유지합니다. 다시 `set`하면 덮어씁니다.

:::info

점프패드인지는 아이템에 숨겨 둔 태그로만 판단합니다. 이름이나 로어를 똑같이 흉내 낸 아이템은 점프패드가 아닙니다. 반대로
예전에 지급한 아이템은 블록을 새로 등록한 뒤에도 계속 점프패드로 설치됩니다.

:::

## 지급과 설치

`/gtjumppad give [플레이어] [개수]`로 지급합니다. 인벤토리가 가득 차면 남는 수량은 발밑에 떨어집니다.

지급받은 아이템으로 블록을 설치하면 그 **좌표**가 점프패드로 기록됩니다. 블록 자체에는 표시가 없으므로, 같은 재질의 일반
블록과 겉보기로는 구분되지 않습니다. `/gtjumppad info`로 설치된 개수를 볼 수 있습니다.

## 발사

점프패드 블록 위로 올라서면 발사됩니다.

| 항목        | 동작                                                                   |
| ----------- | ---------------------------------------------------------------------- |
| 방향        | 바라보는 **수평 방향**. 위아래로 보는 각도는 무시                      |
| 각도        | `launch-pitch-degrees` (기본 35도)                                     |
| 속도        | `launch-speed` (기본 2.2)                                              |
| 다시 발사   | 발을 떼야 다시 발동. 패드 위에 계속 서 있으면 한 번만 발사             |
| 제자리 점프 | 패드 위에서 점프했다가 착지하면 다시 발사                              |
| 쿨다운      | 발사 후 `cooldown-ms`(기본 0.5초) 안에는 다른 패드를 밟아도 발사 안 됨 |

다음 경우에는 발사되지 않습니다.

- `gtjumppad.use` 권한이 없음 (기본값은 모두 있음)
- `enabled-worlds`에 없는 월드
- 탈것에 타고 있음

### 낙하 피해

`prevent-fall-damage`가 `true`면 발사 후 **첫 착지**의 낙하 피해를 막습니다. 발사 직전까지 쌓인 낙하 거리도 지웁니다.

물에 떨어지는 등 착지가 감지되지 않으면 보호가 최대 10초 남습니다. 그 사이 처음 받는 낙하 피해 한 번이 막힙니다.

## 블록 보호와 회수

| 상황                  | 동작                                                                                  |
| --------------------- | ------------------------------------------------------------------------------------- |
| 부수기 (서바이벌)     | 점프패드 아이템 1개가 떨어짐. 일반 블록은 나오지 않음                                 |
| 부수기 (크리에이티브) | 아무것도 떨어지지 않음                                                                |
| 폭발                  | `protect-from-explosion`이 `true`면 부서지지 않음. `false`면 점프패드 아이템이 떨어짐 |
| 불                    | 타지 않음                                                                             |
| 피스톤                | 점프패드 블록을 밀거나 당기는 피스톤은 동작하지 않음                                  |
| 녹거나 쓸려감         | 기록만 지워짐 (얼음이 녹는 경우 등)                                                   |

부술 때 떨어지는 아이템은 **현재 등록된 블록**입니다. 설치한 뒤 `set`으로 블록을 바꿨다면 새 블록이 나옵니다.

보호 구역 플러그인 등이 부수기를 막으면 블록과 기록은 그대로 남습니다.

:::warning

GTJumpPad가 알 수 없는 방법으로 블록이 사라지면 좌표 기록이 남습니다. 예를 들어 WorldEdit로 지우거나, 모래처럼 떨어지는
블록을 점프패드로 쓰는 경우입니다. 이때 그 자리에 다른 방법으로 블록이 생기면 점프패드로 동작합니다. 플레이어가 그
자리에 블록을 직접 설치하면 기록이 지워집니다.

:::
