# 명령어

`/점프패드`로도 쓸 수 있습니다. 모든 명령어는 `gtjumppad.admin` 권한이 필요합니다(기본값 OP).

| 명령어                              | 설명                                                           |
| ----------------------------------- | -------------------------------------------------------------- |
| `/gtjumppad set`                    | 손에 든 블록을 점프패드로 등록 (플레이어만)                    |
| `/gtjumppad give [플레이어] [개수]` | 점프패드 블록 지급. 생략하면 나에게 1개 (콘솔은 플레이어 필수) |
| `/gtjumppad info`                   | 등록된 블록 이름과 설치된 점프패드 개수                        |
| `/gtjumppad reload`                 | `config.yml` 다시 불러오기                                     |

- `give`의 플레이어 이름은 정확히 입력해야 합니다. 개수는 1 이상의 정수입니다.
- 받은 플레이어가 명령어를 실행한 사람이 아니면 받았다는 메시지가 갑니다.

## 권한

| 권한              | 기본값 | 설명             |
| ----------------- | ------ | ---------------- |
| `gtjumppad.use`   | 모두   | 점프패드 발사    |
| `gtjumppad.admin` | OP     | 모든 관리 명령어 |

## reload

`config.yml`의 모든 값이 바로 적용됩니다. 단, `item.auto-lore`와 `item.lore`는 다음 `set`부터 적용되고, 이미 등록한
블록과 지급한 아이템의 로어는 바뀌지 않습니다.
