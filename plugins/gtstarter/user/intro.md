# GTStarter

처음 접속한 플레이어에게 **초반 지급템**(아이템과 소지금)을 한 번 지급하는 플러그인입니다.

## 주요 기능

| 기능               | 설명                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------ |
| 최초 접속 지급     | 처음 접속한 플레이어에게 지급 아이템과 소지금을 한 번만 지급                               |
| GUI 편집           | `/gtstarter edit`로 상자 GUI를 열어 아이템을 넣고 빼는 방식으로 지급 목록 편집             |
| 아이템 그대로 보존 | 인챈트, 이름, 설명, 커스텀 모델 데이터까지 그대로 지급                                     |
| 보류 지급          | 인벤토리가 가득 차면 바닥에 떨어뜨리지 않고 보관했다가, 공간이 생기면 자동으로 이어서 지급 |
| 소지금 지급        | Vault 경제 플러그인이 있으면 소지금도 지급. 없으면 아이템만 지급                           |
| 강제 재지급        | `/gtstarter give`로 특정 플레이어에게 다시 지급                                            |
