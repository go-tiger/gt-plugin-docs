# 명령어

모든 명령어는 `gtstarter.admin` 권한이 필요합니다. 기본값은 OP입니다. `/초기지급`으로도 쓸 수 있습니다.

| 명령어                          | 설명                                           |
| ------------------------------- | ---------------------------------------------- |
| `/gtstarter edit`               | 지급 아이템 편집 GUI 열기 (플레이어만)         |
| `/gtstarter item add [수량]`    | 손에 든 아이템을 지급 목록에 추가 (플레이어만) |
| `/gtstarter item remove <번호>` | 지급 목록에서 아이템 제거                      |
| `/gtstarter item list`          | 지급 목록 보기                                 |
| `/gtstarter give <닉네임>`      | 플레이어에게 처음부터 다시 지급                |
| `/gtstarter reload`             | `config.yml`과 지급 목록 다시 불러오기         |

## edit

27칸짜리 상자 GUI가 열리고 현재 지급 아이템이 채워져 있습니다. 아이템을 자유롭게 넣고 빼고 **창을 닫으면 그 상태가
그대로 저장**됩니다.

- 같은 아이템은 수량이 합쳐져 한 종류로 저장됩니다. 예를 들어 빵 64개를 두 칸에 넣으면 "빵 128개" 하나가 됩니다.
- GUI 안의 아이템은 설정을 보여 주는 사본입니다. 창을 닫으면 사라지고 내 인벤토리로 돌아오지 않습니다. 반대로 GUI에 넣은
  아이템도 돌려받을 수 없으니, 넣을 아이템은 미리 복사해 두세요.

:::warning GUI는 27칸이라 한 번에 27묶음까지만 보입니다. 지급 목록이 27묶음보다 많으면(`item add`로 많이 추가한 경우 등)
넘치는 아이템은 GUI에 표시되지 않고, **창을 닫으면 그 아이템은 목록에서 빠집니다.** 목록이 많을 때는 `item` 명령어로
관리하세요. :::

## item

```
/gtstarter item add          # 손에 든 개수만큼 추가
/gtstarter item add 200      # 200개 추가 (최대 스택보다 많아도 됨)
/gtstarter item list
/gtstarter item remove 2     # list에서 2번 항목 제거
```

- `add`는 손에 든 아이템의 인챈트, 이름 등을 그대로 저장합니다. 이미 목록에 같은 아이템이 있으면 수량이 더해집니다.
- 번호는 `item list`에 나오는 번호(1부터)를 씁니다.

## give

대상 플레이어의 지급 기록, 보류 아이템, 소지금 지급 기록을 모두 지우고 **처음부터 다시 지급**합니다. 소지금도 다시
입금됩니다.

- 대상은 **접속 중인 플레이어**여야 합니다.
- 보류 아이템을 처리하는 중이면 `give-busy` 메시지가 나옵니다. 잠시 후 다시 실행하세요.

## reload

`config.yml`과 지급 목록을 다시 불러옵니다.

:::note `economy` 설정(`enabled`, `retry-seconds`)은 서버 시작 시에만 적용됩니다. 바꾼 뒤에는 서버를 재시작하세요. :::
