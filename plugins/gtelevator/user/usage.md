# 사용 방법

## 1. 엘리베이터 블록 등록 (관리자)

엘리베이터로 쓸 블록을 손에 들고 실행합니다.

```
/gtelevator set
```

- 손에 든 아이템이 이름, 설명, 인챈트, 커스텀 모델 데이터까지 그대로 등록됩니다. `item.auto-lore`가 켜져 있으면 사용법
  안내 설명이 덧붙습니다.
- 등록된 블록은 한 종류뿐입니다. 다시 실행하면 새 블록으로 바뀝니다(`set-overwritten`).
- 블록을 바꿔도 **이미 설치한 엘리베이터와 이미 지급한 아이템은 계속 동작**합니다.

:::tip 어떤 블록이 좋은가요 양털, 철 블록처럼 **꽉 찬 단단한 블록**을 쓰세요.

- 반 블록, 카펫 같은 블록은 Spigot에서 점프가 잘 감지되지 않습니다.
- 모래, 자갈처럼 떨어지는 블록은 아래가 비면 떨어져서 엘리베이터 기능이 사라집니다. :::

## 2. 블록 지급

```
/gtelevator give                # 나에게 1개
/gtelevator give Steve 16       # Steve에게 16개
```

엘리베이터 블록은 일반 블록과 생김새가 같아도 **이 명령어로 지급한 아이템만** 엘리베이터가 됩니다. 이름이나 설명을
똑같이 꾸며도 엘리베이터로 인정되지 않습니다.

## 3. 설치

같은 **x, z 좌표**(같은 기둥)에 엘리베이터 블록을 층마다 하나씩 설치합니다.

```
  [엘리베이터]  ← 3층 (y=80)
       ┃
  [엘리베이터]  ← 2층 (y=72)
       ┃
  [엘리베이터]  ← 1층 (y=64)
```

- 층 사이 간격은 자유입니다. 최대 `max-distance`(기본 256칸)까지 떨어질 수 있습니다.
- 블록 위로 **두 칸**이 비어 있어야 도착할 수 있습니다(`safe-teleport`).
- 블록 사이가 막혀 있어도 상관없습니다. 벽과 천장을 통과해 이동합니다.

## 4. 이동

엘리베이터 블록 위에 서서:

| 동작     | 이동                                           |
| -------- | ---------------------------------------------- |
| 점프     | 같은 기둥에서 바로 위의 엘리베이터 블록 위로   |
| 웅크리기 | 같은 기둥에서 바로 아래의 엘리베이터 블록 위로 |

- 한 번에 한 층씩 이동합니다. 연속 이동은 `cooldown-ms`(기본 0.25초) 간격으로만 됩니다.
- 이동하면 액션바에 `▲ 2층 (로비)`처럼 층 정보가 나옵니다. 층 번호는 그 기둥에서 **맨 아래 블록을 1층**으로 셉니다.
- 탈것을 타고 있으면 내린 뒤 이동합니다.
- 이동한 뒤에는 낙하 피해가 초기화됩니다.

## 5. 층 이름 (선택)

엘리베이터 블록 위에 서서 실행합니다.

```
/gtelevator floor set 로비
/gtelevator floor remove
```

액션바의 `%label%` 자리에 이 이름이 나옵니다. 이름이 없으면 `y=72`처럼 좌표가 나옵니다.

## 블록 부수기

엘리베이터 블록을 부수면 **엘리베이터 블록 아이템**이 떨어지므로, 다시 설치해도 엘리베이터로 동작합니다. 크리에이티브
모드에서 부수면 아무것도 떨어지지 않습니다.

부순 블록에 층 이름이 있었다면 함께 지워집니다.

:::note 떨어지는 아이템은 **지금 등록된** 엘리베이터 블록입니다. `/gtelevator set`으로 블록을 바꾼 뒤에 예전 블록을
부수면 새 블록으로 바뀌어 떨어집니다. :::

## 블록 보호

| 위협                  | 처리                                                                                                   |
| --------------------- | ------------------------------------------------------------------------------------------------------ |
| 폭발 (TNT, 크리퍼 등) | `protect-from-explosion: true`이면 부서지지 않음. `false`이면 부서지고 엘리베이터 블록 아이템이 떨어짐 |
| 불                    | 타지 않음                                                                                              |
| 피스톤                | 엘리베이터 블록을 밀거나 당기는 피스톤은 동작하지 않음                                                 |
