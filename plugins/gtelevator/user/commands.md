# 명령어

`/엘리베이터`로도 쓸 수 있습니다. 모든 명령어는 `gtelevator.admin` 권한이 필요합니다(기본값 OP).

| 명령어                             | 설명                                                               |
| ---------------------------------- | ------------------------------------------------------------------ |
| `/gtelevator set`                  | 손에 든 블록을 엘리베이터 블록으로 등록 (플레이어만)               |
| `/gtelevator give [닉네임] [개수]` | 엘리베이터 블록 지급. 닉네임을 생략하면 나, 개수를 생략하면 1개    |
| `/gtelevator floor set <이름>`     | 발밑 엘리베이터 블록에 층 이름 등록. 이름에 공백 가능 (플레이어만) |
| `/gtelevator floor remove`         | 발밑 엘리베이터 블록의 층 이름 제거 (플레이어만)                   |
| `/gtelevator info`                 | 등록된 블록, 설치된 블록 수, 점프 감지 방식                        |
| `/gtelevator reload`               | `config.yml` 다시 불러오기                                         |

## 권한

| 권한               | 기본값        | 설명                  |
| ------------------ | ------------- | --------------------- |
| `gtelevator.use`   | 모든 플레이어 | 점프, 웅크림으로 이동 |
| `gtelevator.admin` | OP            | 모든 명령어           |

## 참고

- `give`의 대상은 접속 중이어야 합니다. 인벤토리가 가득 차면 남는 만큼 발밑에 떨어집니다.
- `set`은 설치할 수 있는 블록만 등록할 수 있습니다(`set-not-block`).
- `reload`는 모든 설정에 바로 적용됩니다. 재시작할 필요가 없습니다.
