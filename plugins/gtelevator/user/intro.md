# GTElevator

**엘리베이터 블록** 위에서 점프하면 위층으로, 웅크리면 아래층으로 순간이동하는 플러그인입니다.

## 주요 기능

| 기능              | 설명                                                                                 |
| ----------------- | ------------------------------------------------------------------------------------ |
| 점프, 웅크림 이동 | 같은 기둥(x, z)에 설치된 바로 위, 아래 엘리베이터 블록으로 이동                      |
| 블록 직접 지정    | 관리자가 손에 든 블록을 엘리베이터 블록으로 등록. 이름, 설명, 인챈트 효과까지 그대로 |
| 층 표시           | 이동하면 액션바에 층 번호와 층 이름 표시                                             |
| 층 이름           | 층마다 "로비", "옥상" 같은 이름 등록                                                 |
| 안전 이동         | 도착 지점이 막혀 있으면 이동하지 않음                                                |
| 블록 보호         | 폭발, 화재, 피스톤으로부터 보호                                                      |
| 효과              | 이동 소리와 파티클                                                                   |
