# 설치하기

## 요구 사항

| 항목 | 요구 사항                                           |
| ---- | --------------------------------------------------- |
| 서버 | Spigot 1.20.1 이상 (Paper 등 Spigot 호환 서버 포함) |
| Java | 17 이상                                             |

다른 플러그인은 필요 없습니다.

## 설치

1. `GTRandomBox-<버전>.jar`를 서버의 `plugins/` 폴더에 넣습니다.
2. 서버를 실행합니다. 다음 파일과 폴더가 자동으로 생성됩니다.

| 경로                                       | 설명                                                       |
| ------------------------------------------ | ---------------------------------------------------------- |
| `plugins/GTRandomBox/config.yml`           | 확률 상한, 동시 개봉, 로그, 연출, 메시지 설정              |
| `plugins/GTRandomBox/boxes/<이름>.yml`     | 박스마다 하나씩. 박스 아이템, 보상 아이템, 확률, 표시 이름 |
| `plugins/GTRandomBox/logs/open-<날짜>.log` | 개봉 로그 (`logging.to-file: true`일 때)                   |

3. [박스 만들기](./creating.md)를 보고 박스를 만듭니다.
