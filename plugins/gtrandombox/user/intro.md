# GTRandomBox

우클릭하면 룰렛 연출과 함께 **확률에 따라 아이템 하나**가 나오는 랜덤박스 플러그인입니다.

## 주요 기능

| 기능             | 설명                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------ |
| 여러 종류의 박스 | 이름별로 박스를 만들고 각각 보상 아이템과 확률을 설정                                |
| GUI 설정         | 보상 아이템은 상자 GUI에 넣어서, 확률과 표시 이름은 GUI에서 클릭 후 채팅으로 입력    |
| 확률 자동 분배   | 확률을 정하지 않은 아이템에는 남은 몫을 자동으로 나눔                                |
| 룰렛 연출        | 플레이어 앞에 아이템이 떠서 바뀌다가 당첨 아이템에서 멈추고 회전. 소리, 파티클, 불꽃 |
| 위조 방지        | 지급한 박스 아이템만 열림. 이름을 똑같이 바꾼 아이템은 열리지 않음                   |
| 개봉 로그        | 개봉과 지급 내역을 콘솔과 파일에 기록                                                |
