# 명령어

`/랜덤박스`, `/randombox`, `/rb`로도 쓸 수 있습니다. 모든 명령어는 `gtrandombox.admin` 권한이 필요합니다(기본값 OP).

| 명령어                              | 설명                                                             |
| ----------------------------------- | ---------------------------------------------------------------- |
| `/gtrandombox`                      | 명령어 도움말                                                    |
| `/gtrandombox 생성 <이름>`          | 박스 생성                                                        |
| `/gtrandombox 삭제 <이름>`          | 박스 삭제. 그 박스의 설정, 관리 GUI를 열고 있는 사람은 창이 닫힘 |
| `/gtrandombox 목록`                 | 박스 목록                                                        |
| `/gtrandombox 설정 <이름>`          | 보상 아이템 GUI (플레이어만)                                     |
| `/gtrandombox 관리 <이름>`          | 확률, 표시 이름 GUI (플레이어만)                                 |
| `/gtrandombox 박스설정 <이름>`      | 손에 든 아이템을 박스 아이템으로 지정 (플레이어만)               |
| `/gtrandombox 지급 <이름> [닉네임]` | 박스 1개 지급. 닉네임을 생략하면 나                              |
| `/gtrandombox 리로드`               | `config.yml`과 모든 박스 파일 다시 불러오기                      |

## 권한

| 권한                | 기본값        | 설명                                                   |
| ------------------- | ------------- | ------------------------------------------------------ |
| `gtrandombox.admin` | OP            | 모든 명령어                                            |
| `gtrandombox.use`   | 모든 플레이어 | 현재 사용하지 않음. 이 권한이 없어도 박스를 열 수 있음 |

## 참고

- `지급`의 대상은 접속 중이어야 합니다.
- 이름에 쓸 수 없는 문자로 `생성`하면 `box-already-exists` 메시지가 나옵니다.
