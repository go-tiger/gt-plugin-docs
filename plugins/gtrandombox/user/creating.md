# 박스 만들기

모든 명령어는 `gtrandombox.admin` 권한이 필요합니다(기본값 OP). `/랜덤박스`, `/rb`로도 쓸 수 있습니다.

## 1. 박스 생성

```
/gtrandombox 생성 무기상자
```

- 이름은 공백 없이 한 단어입니다. `/ \ : * ? " < > |`는 쓸 수 없습니다.
- 대소문자를 구분하지 않습니다(`Box`와 `box`는 같은 박스).

## 2. 보상 아이템 넣기

```
/gtrandombox 설정 무기상자
```

54칸 상자 GUI가 열립니다. 당첨될 수 있는 아이템을 원하는 칸에 넣고 창을 닫으면 저장됩니다.

- **한 칸이 보상 하나**입니다. 다이아몬드 16개를 한 칸에 넣으면 당첨 시 다이아몬드 16개를 줍니다.
- 이름, 인챈트, 설명 등이 그대로 지급됩니다.
- 칸을 비우고 닫으면 그 보상은 확률, 표시 이름과 함께 지워집니다.

:::warning 설정 GUI에 넣은 아이템은 **돌려받을 수 없습니다.** 창을 닫으면 설정으로 저장되고 사라집니다. 반대로 다시
열었을 때 GUI에서 아이템을 꺼내면 그 아이템을 가질 수 있으니(복사), 관리자 외에는 이 명령어를 쓰지 못하게 하세요. :::

## 3. 확률과 표시 이름 정하기

```
/gtrandombox 관리 무기상자
```

보상 아이템이 칸 그대로 표시되고, 설명에 지금 확률과 표시 이름이 나옵니다.

| 클릭   | 동작                                            |
| ------ | ----------------------------------------------- |
| 좌클릭 | 확률 입력. GUI가 닫히고 채팅으로 숫자 입력      |
| 우클릭 | 표시 이름 입력. GUI가 닫히고 채팅으로 이름 입력 |

입력이 끝나면 관리 GUI가 다시 열립니다. `취소`를 입력하거나 `input-timeout-seconds`(기본 60초)가 지나면 취소됩니다. 채팅
입력 중에는 그 채팅이 다른 사람에게 보이지 않습니다.

안내 메시지에 나오는 슬롯 번호는 **0부터** 셉니다. 맨 왼쪽 위 칸이 0번입니다.

### 확률은 가중치입니다

확률 숫자는 퍼센트가 아니라 **다른 보상과의 비율**(가중치)입니다.

| 보상          | 확률 | 실제 당첨 확률 |
| ------------- | ---- | -------------- |
| 다이아몬드 검 | 1    | 1 / 100 = 1%   |
| 철 검         | 9    | 9 / 100 = 9%   |
| 나무 검       | 90   | 90 / 100 = 90% |

합이 100일 필요는 없습니다. `1, 1, 2`로 정하면 25%, 25%, 50%입니다.

### 확률을 정하지 않은 보상 (0)

확률이 0인 보상은 다음 규칙으로 자동 분배됩니다.

| 상황                      | 처리                                                 |
| ------------------------- | ---------------------------------------------------- |
| 모든 보상이 0             | 100을 개수대로 똑같이 나눔 (전부 같은 확률)          |
| 정한 보상의 합이 100 미만 | 100에서 그 합을 뺀 나머지를 0인 보상끼리 똑같이 나눔 |
| 정한 보상의 합이 100 이상 | 0인 보상은 **절대 나오지 않음**                      |

예를 들어 보상이 4개이고 하나만 `40`으로 정하면, 나머지 3개는 각각 `20`이 되어 40%, 20%, 20%, 20%가 됩니다.

### 표시 이름

당첨 메시지와 로그에 나오는 이름입니다. 정하지 않으면 아이템 이름, 그것도 없으면 `DIAMOND_SWORD` 같은 아이템 ID가
나옵니다. 실제 지급되는 아이템의 이름은 바뀌지 않습니다.

## 4. 박스 아이템 정하기

플레이어가 들고 우클릭할 **박스 아이템**을 손에 들고 실행합니다.

```
/gtrandombox 박스설정 무기상자
```

상자, 셜커 상자, 머리 등 아무 아이템이나 됩니다. 이 아이템이 없으면 박스를 지급할 수 없습니다.

## 5. 지급

```
/gtrandombox 지급 무기상자          # 나에게
/gtrandombox 지급 무기상자 Steve    # Steve에게
```

- 한 번에 **1개**씩 지급합니다.
- 지급되는 아이템의 이름은 항상 `&e<박스 이름>`(노란색)으로 바뀝니다. 박스 아이템에 붙인 이름은 쓰이지 않습니다.

:::warning 받는 사람의 인벤토리가 가득 차 있으면 **박스가 지급되지 않고 사라집니다.** 바닥에 떨어지지 않습니다. 지급하기
전에 인벤토리에 빈칸이 있는지 확인하세요. :::

## 수정과 삭제

- 보상 아이템, 확률, 표시 이름, 박스 아이템은 언제든 다시 설정할 수 있습니다. 이미 지급한 박스에도 바로 적용됩니다.
- `/gtrandombox 삭제 <이름>`으로 지우면 이미 지급된 그 박스는 열리지 않습니다(`box-not-found`). 사라지지는 않습니다.
- `boxes/<이름>.yml`을 직접 고친 뒤에는 `/gtrandombox 리로드`를 실행하세요.
