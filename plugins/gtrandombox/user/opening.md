# 박스 열기

박스 아이템을 손에 들고 **우클릭**합니다. 블록을 보고 있어도, 허공을 보고 있어도 됩니다.

## 개봉 조건

| 조건                                                           | 안 되면         |
| -------------------------------------------------------------- | --------------- |
| 지급된 박스 아이템일 것                                        | 아무 일도 없음  |
| 박스가 아직 있을 것                                            | `box-not-found` |
| 보상이 하나 이상 있을 것                                       | `open-no-items` |
| 인벤토리 빈칸이 하나 이상 있을 것                              | `open-no-space` |
| 다른 박스를 여는 중이 아닐 것 (`allow-concurrent-open: false`) | `open-already`  |

조건을 통과하면 **박스 1개가 바로 사라지고** 연출이 시작됩니다.

## 룰렛 연출

1. 플레이어 앞(기본 2칸 앞, 1.5칸 위)에 아이템이 떠오릅니다.
2. 보상 아이템이 무작위로 바뀌며 점점 느려집니다(기본 100번).
3. 마지막 3번은 당첨 아이템이 보입니다.
4. 폭발 파티클, 불꽃, 레벨업 소리와 함께 당첨 아이템이 회전합니다.
5. 연출이 끝나면 아이템을 받고 결과 메시지가 나옵니다.

기본 설정으로 연출은 약 10초 걸립니다. `animation.enabled: false`이면 연출 없이 바로 받습니다.

- 당첨 아이템은 연출이 시작되기 전에 이미 정해집니다.
- 받을 때 인벤토리가 가득 차 있으면 발밑에 떨어집니다(`open-dropped`).
- 결과 메시지의 `(xx%)`는 실제 퍼센트가 아니라 그 보상의 **확률(가중치) 값**입니다.

:::danger **연출 도중에 접속을 끊지 마세요.** 박스는 이미 사라졌는데 보상이 지급되지 않을 수 있습니다. 서버가 꺼진
경우도 마찬가지입니다. 이런 경우 운영자가 개봉 로그를 보고 수동으로 지급해야 합니다. :::

## 개봉 로그

| 시점           | 로그                                                                           |
| -------------- | ------------------------------------------------------------------------------ |
| 연출 시작 직전 | `개봉: player=Steve (uuid=...) box=무기상자 → 당첨: 다이아몬드 검 x1 (확률 1)` |
| 지급 후        | `지급완료: player=Steve box=무기상자 item=다이아몬드 검 x1`                    |

`개봉` 로그는 있는데 `지급완료` 로그가 없으면 보상을 받지 못한 것입니다. 로그는 콘솔과
`plugins/GTRandomBox/logs/open-<날짜>.log`에 남습니다.
