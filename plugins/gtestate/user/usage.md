# 매물 등록과 구매

## 매물 등록 (관리자)

1. 매물 위치에 표시판을 설치합니다. 내용은 비워 두어도 됩니다.
2. 표시판을 바라본 채(5칸 이내) 명령어를 실행합니다.

```
/gtestate create <이름> <HOUSE|CAFE> <가격>
```

```
/gtestate create 1번집 HOUSE 500000
```

3. 표시판 앞면이 판매 중 형식으로 바뀝니다.

```
[매매]
1번집
500,000원
우클릭하여 구매
```

- 이름은 공백 없이 한 단어로 씁니다. 대소문자를 구분하지 않고, 같은 이름은 등록할 수 없습니다.
- 가격은 1 이상의 정수입니다.
- 이미 매물로 등록된 표시판에는 다시 등록할 수 없습니다.

:::note 표시판은 한 줄에 15자까지만 표시됩니다. 색상 코드(`&1` 등)도 2자로 셉니다. 이름이 길면 표시판에서 잘리니 짧게
지으세요. :::

## 구매 (플레이어)

판매 중인 표시판을 **우클릭**하면 구매를 시도합니다.

1. 소지금이 구매 조건에 맞는지 확인합니다. 기본값(`exact-amount: true`)은 소지금이 가격과 정확히 같아야 합니다.
2. 최대 소유 수를 넘지 않는지 확인합니다.
3. 소지금에서 가격을 빼고 소유자로 등록합니다.
4. 표시판이 판매 완료 형식으로 바뀌고, `broadcast-purchase`가 켜져 있으면 서버 전체에 알립니다.

```
[판매완료]
1번집
소유자
Steve
```

두 사람이 거의 동시에 같은 매물을 사려고 하면 한 명만 구매에 성공합니다. 실패한 사람은 `purchase-busy` 또는
`purchase-failed` 메시지를 받고, 이미 빠져나간 돈은 자동으로 환불됩니다.

## 정보 조회

다음 방법으로 클릭하면 구매하지 않고 정보만 봅니다.

- 표시판 **좌클릭**
- **웅크린 채 우클릭** (`sneak-to-inspect: true`일 때)

```
─── 1번집 ───
종류: 집
가격: 500,000원
상태: 판매 중
내 소지금: 320,000원
부족한 금액: 180,000원
소지금이 가격과 정확히 일치해야 구매할 수 있습니다.
```

## 표시판 보호

등록된 표시판은 파괴, 폭발, 물리 갱신(붙어 있는 블록이 없어지는 경우 등)으로 없어지지 않습니다.

`gtestate.admin` 권한이 있는 관리자는 **웅크린 채로** 부수면 표시판을 파괴할 수 있습니다. 다만 이렇게 부수면 매물 등록은
그대로 남습니다. 표시판을 없애려면 먼저 `/gtestate remove`로 등록을 해제하세요.
