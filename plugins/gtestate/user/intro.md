# GTEstate

표시판으로 **부동산 매물**(집, 카페)을 사고파는 플러그인입니다. 관리자가 표시판을 매물로 등록하면, 플레이어가 표시판을
우클릭해 소지금으로 구매합니다.

## 주요 기능

| 기능        | 설명                                                                             |
| ----------- | -------------------------------------------------------------------------------- |
| 표시판 매물 | 표시판을 바라보고 명령어로 매물 등록. 상태에 따라 표시판 내용이 자동으로 바뀜    |
| 우클릭 구매 | Vault 경제 소지금으로 구매. 기본값은 **소지금이 가격과 정확히 같아야** 구매 가능 |
| 정보 조회   | 좌클릭 또는 웅크린 채 우클릭하면 가격, 상태, 부족한 금액 표시                    |
| 소유 제한   | 전체, 종류별 최대 소유 수 설정                                                   |
| 표시판 보호 | 등록된 표시판은 파괴, 폭발, 물리 갱신으로부터 보호                               |
| 거래 이력   | 구매와 관리자 소유자 변경을 SQLite에 기록                                        |

출입이나 건축 권한은 관리하지 않습니다. 필요하면 다른 플러그인이나 Skript에서 [API](../dev/api.md)로 소유 여부를 확인해
처리하세요.
