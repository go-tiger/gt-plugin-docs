# 명령어

`/부동산`으로도 쓸 수 있습니다. 모든 하위 명령어는 `gtestate.admin` 권한이 필요합니다(기본값 OP).

| 명령어                                         | 설명                                       |
| ---------------------------------------------- | ------------------------------------------ |
| `/gtestate create <이름> <HOUSE\|CAFE> <가격>` | 바라보는 표시판을 매물로 등록 (플레이어만) |
| `/gtestate remove <이름>`                      | 매물 등록 해제. 표시판은 빈 표시판이 됨    |
| `/gtestate setprice <이름> <가격>`             | 가격 변경                                  |
| `/gtestate setowner <이름> <닉네임>`           | 소유자 지정 (돈이 오가지 않음)             |
| `/gtestate setowner <이름> none`               | 소유자를 지우고 다시 판매 중으로 변경      |
| `/gtestate list [HOUSE\|CAFE]`                 | 매물 목록 (이름순)                         |
| `/gtestate info <이름>`                        | 매물 정보                                  |
| `/gtestate reload`                             | `config.yml` 다시 불러오기                 |

## 권한

| 권한             | 기본값        | 설명                                    |
| ---------------- | ------------- | --------------------------------------- |
| `gtestate.buy`   | 모든 플레이어 | 표시판 우클릭 구매                      |
| `gtestate.admin` | OP            | 모든 관리 명령어, 웅크린 채 표시판 파괴 |

## 주의 사항

- 매물 이름은 64자까지 쓸 수 있습니다.
- **`remove`와 `setowner`는 환불하지 않습니다.** 팔린 매물을 해제하거나 소유자를 바꿔도 이전 소유자의 돈은 돌려주지
  않습니다. 필요하면 경제 플러그인 명령어로 따로 지급하세요.
- **`setowner`는 최대 소유 수를 확인하지 않습니다.** 제한을 넘겨서 지정할 수도 있습니다.
- **`setprice`는 팔린 매물에도 적용됩니다.** 소유자는 그대로이고 가격만 바뀝니다.
- `setowner`의 닉네임은 서버에 한 번이라도 접속한 플레이어여야 합니다.
- 소유자 이름은 구매하거나 지정한 시점의 닉네임으로 저장됩니다. 나중에 닉네임을 바꿔도 표시판과 목록에는 예전 이름이
  나옵니다.

## reload

`config.yml`을 다시 불러옵니다. 구매 규칙과 메시지는 바로 적용됩니다.

:::note `sign-format`과 `type-names`를 바꿔도 **이미 설치된 표시판은 바로 바뀌지 않습니다.** 서버를 재시작하거나, 해당
청크가 다시 로드되거나, 그 매물의 상태가 바뀔 때 새 형식으로 갱신됩니다. `economy` 설정은 서버를 재시작해야 적용됩니다.
:::
