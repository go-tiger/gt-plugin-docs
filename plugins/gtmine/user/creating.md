# 광산 만들기

모든 명령어는 `gtmine.admin` 권한이 필요합니다(기본값 OP). `/광산`으로도 쓸 수 있습니다.

## 두 가지 모드

| 모드          | 리젠 포인트 모습 | 하는 일                                   |
| ------------- | ---------------- | ----------------------------------------- |
| **배치 모드** | 마커 블록        | 마커를 설치하고 부수며 포인트를 깔고 지움 |
| **채굴 모드** | 광물, 돌, 기반암 | 플레이어가 캐면 기반암이 되었다가 리젠    |

광산은 처음에 배치 모드입니다. 광산마다 모드가 따로 있습니다.

## 1. 광산 정의

`config.yml`의 `areas` 아래에 광산을 정의합니다. 기본으로 `main`이 있습니다.

```yaml
areas:
  main:
    pool:
      - material: STONE
        weight: 372
      - material: COAL_ORE
        weight: 190
      - material: DIAMOND_ORE
        weight: 40
    respawn-seconds: 15
```

자세한 내용은 [설정](./config.md#areas)을 참고하세요. 바꾼 뒤에는 `/gtmine reload`를 실행합니다.

## 2. 마커 받기

```
/gtmine give                       # 나에게 1개, default-area 광산
/gtmine give Steve 64              # Steve에게 64개
/gtmine give Steve 64 -area deep   # deep 광산용
```

- 마커에는 **소속 광산**이 들어 있습니다. 아이템 설명에 `소속 광산: main`처럼 나옵니다.
- 이미 가진 마커의 소속 광산을 바꾸려면 손에 들고 `/gtmine setarea <광산>`을 실행합니다.
- 닉네임 없이 개수만 쓸 수는 없습니다(`/gtmine give 64`는 `64`라는 플레이어를 찾습니다).

마커 블록의 재질은 `marker-material`(기본 `STRUCTURE_VOID`)입니다. 이 명령어로 받은 마커만 리젠 포인트가 되고, 같은
재질의 일반 블록은 인정되지 않습니다.

## 3. 배치 모드에서 마커 설치

광물이 생기길 원하는 자리에 마커 블록을 설치합니다. 설치할 때마다 `리젠 포인트가 등록되었습니다 (main, 총 n개)`가
나옵니다.

- 잘못 놓은 마커는 부수면 등록이 풀리고 마커 아이템이 떨어집니다(크리에이티브 모드에서는 안 떨어짐).
- 채굴 모드에서는 포인트를 지울 수 없습니다. 지우려면 먼저 `stop`으로 배치 모드로 돌아가세요.

## 4. 채굴 모드로 전환

```
/gtmine start          # default-area 광산
/gtmine start main
```

모든 리젠 포인트가 확률 풀에 따라 광물이나 돌로 바뀝니다.

## 채굴과 리젠

1. 플레이어가 리젠 포인트를 캐면 바닐라처럼 아이템, 경험치가 나오고 도구 내구도가 닳습니다.
2. 바로 그 자리가 **기반암**으로 바뀝니다.
3. `respawn-seconds` 뒤에 확률 풀에서 다시 뽑은 블록으로 바뀌고, 파티클과 소리가 납니다.

- 리젠 시간은 무엇을 캤든 같습니다.
- 서버가 꺼져 있던 시간도 리젠 시간에 포함됩니다. 재시작했을 때 이미 지났으면 바로 리젠됩니다.
- 리젠 포인트가 아닌 블록은 평소처럼 캐집니다.

## 운영 명령어

| 명령어                   | 동작                                                                                         |
| ------------------------ | -------------------------------------------------------------------------------------------- |
| `/gtmine stop [광산]`    | 배치 모드로 전환. 진행 중인 리젠을 취소하고 모든 포인트를 마커로 되돌림                      |
| `/gtmine restart [광산]` | 모드와 상관없이 모든 포인트를 다시 뽑아 채굴 모드로 전환. 기반암 상태인 포인트도 바로 채워짐 |
| `/gtmine clear [광산]`   | 지금 광물이나 돌인 포인트를 전부 **돌**로 바꿈. 기반암 포인트는 그대로. 채굴 모드 유지       |

`restart`는 확률 풀을 바꾼 뒤 광산 전체를 새로 채우고 싶을 때나, 마커만 깔아 두고 서버를 재시작해 상태가 꼬였을 때
씁니다.

## 광산 확인

```
/gtmine list           # 모든 광산의 모드와 포인트 수
/gtmine info main      # main 광산의 모드와 포인트 수
/gtmine pool main      # main 광산의 확률표 (퍼센트 포함)
```

:::warning

- **WorldEdit 등으로 리젠 포인트를 바꾸거나 지우면 추적되지 않습니다.** 포인트는 좌표로 기록되므로, 블록이 바뀌어도
  리젠은 그 좌표에서 계속 일어납니다.
- 채굴 모드인 광산을 `config.yml`에서 지우거나 확률 풀을 비우면, 기반암이 된 포인트가 **리젠되지 않고 기반암으로
  남습니다.** 광산을 없애려면 먼저 `stop`한 뒤 마커를 부수세요.
- 확률 풀에 모래, 자갈처럼 **떨어지는 블록**을 넣지 마세요. 아래가 비면 떨어져서 포인트 위치가 어긋납니다. :::
