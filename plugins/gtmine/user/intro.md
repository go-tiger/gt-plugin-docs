# GTMine

캐면 일정 시간 뒤에 **확률에 따라 광물이 다시 생기는** 광산 플러그인입니다. 관리자가 광산 위치에 리젠 포인트를 깔아
두면, 플레이어가 캔 자리가 기반암이 되었다가 다시 광물이나 돌로 바뀝니다.

## 주요 기능

| 기능                 | 설명                                                        |
| -------------------- | ----------------------------------------------------------- |
| 리젠 포인트          | 마커 블록을 설치한 자리가 광물이 다시 생기는 칸이 됨        |
| 확률 풀              | 광산마다 어떤 블록이 얼마의 확률로 나올지 가중치로 설정     |
| 여러 광산            | 광산(area)마다 확률 풀과 리젠 시간을 따로 설정              |
| 배치 모드, 채굴 모드 | 배치 모드에서 마커를 깔고, 채굴 모드로 바꾸면 광물이 생김   |
| 바닐라 드롭          | 행운, 섬세한 손길, 경험치, 도구 내구도가 바닐라 그대로 적용 |
| 재시작 복구          | 서버를 껐다 켜도 남은 리젠 시간을 이어서 계산               |
| 보호                 | 피스톤과 폭발로부터 리젠 포인트 보호                        |
