# 명령어

`/광산`으로도 쓸 수 있습니다. 모든 명령어는 `gtmine.admin` 권한이 필요합니다(기본값 OP). `[광산]`을 생략하면
`default-area`(기본 `main`)를 씁니다.

| 명령어                                        | 설명                                          |
| --------------------------------------------- | --------------------------------------------- |
| `/gtmine give [닉네임] [개수] [-area <광산>]` | 마커 지급. 인벤토리가 가득 차면 발밑에 떨어짐 |
| `/gtmine setarea <광산>`                      | 손에 든 마커의 소속 광산 변경 (플레이어만)    |
| `/gtmine start [광산]`                        | 배치 모드에서 채굴 모드로                     |
| `/gtmine stop [광산]`                         | 채굴 모드에서 배치 모드로                     |
| `/gtmine restart [광산]`                      | 모든 포인트를 다시 뽑아 채굴 모드로           |
| `/gtmine clear [광산]`                        | 광물 포인트를 모두 돌로                       |
| `/gtmine info [광산]`                         | 모드와 포인트 수                              |
| `/gtmine list`                                | 광산 목록                                     |
| `/gtmine pool [광산]`                         | 확률표                                        |
| `/gtmine reload`                              | `config.yml` 다시 불러오기                    |

## 권한

| 권한           | 기본값 | 설명        |
| -------------- | ------ | ----------- |
| `gtmine.admin` | OP     | 모든 명령어 |

채굴 자체에는 권한이 필요 없습니다. 리젠 포인트를 캘 수 있는지는 다른 보호 플러그인(WorldGuard 등)의 설정을 따릅니다.
보호 플러그인이 파괴를 막으면 리젠도 일어나지 않습니다.

## 실패 메시지

| 상황                                 | 메시지                  |
| ------------------------------------ | ----------------------- |
| `config.yml`에도, 마커에도 없는 광산 | `area-not-found`        |
| 이미 채굴 모드인데 `start`           | `area-already-active`   |
| 이미 배치 모드인데 `stop`            | `area-already-inactive` |
| 포인트가 하나도 없음                 | `area-no-points`        |
| 확률 풀이 없거나 모든 가중치가 0     | `area-invalid-pool`     |
| `clear`할 광물 포인트가 없음         | `area-no-ore-points`    |

마커를 설치하거나 `give -area`로 지급하기만 해도 광산 이름이 목록에 생깁니다. 하지만 `config.yml`에 확률 풀이 없으면
`start`할 수 없습니다.
