# 드랍 진행

모든 명령어는 `gtsupplydrop.admin` 권한이 필요합니다(기본값 OP). `/보급상자`로도 쓸 수 있습니다.

## 정기 드랍

```
/gtsupplydrop start        # interval-minutes(기본 10분)마다
/gtsupplydrop start 5      # 5분마다
/gtsupplydrop stop
```

- **첫 드랍은 시작하고 한 주기 뒤**에 떨어집니다. 바로 떨어뜨리려면 `force`를 함께 쓰세요.
- 이미 돌고 있을 때 `start`하면 새 주기로 다시 시작합니다.
- `stop`해도 이미 떨어지고 있는 상자는 그대로 착지합니다.
- 정기 드랍 상태는 저장되지 않습니다. 서버를 재시작하면 멈춘 상태가 됩니다. 서버가 켜질 때 자동으로 시작하려면
  `auto-start-on-enable: true`로 두세요.

## 즉시 드랍

```
/gtsupplydrop force
```

정기 드랍과 따로 한 번 떨어뜨립니다. 다음 정기 드랍 시각에는 영향이 없습니다.

## 드랍 과정

1. 활성 구역 안에서 무작위 x, z를 고르고, 그 자리의 가장 높은 블록 바로 위를 착지 지점으로 정합니다.
2. 착지 지점 위 `drop-height`(기본 150) 높이에 상자가 나타나고, **그 순간 전체에 x, z 좌표를 알립니다.**
3. 상자가 매 틱 `fall-speed-blocks-per-tick`(기본 0.3칸)씩 내려옵니다. 파티클과 소리가 납니다.
4. 착지하면 실제 상자가 설치되고, 같은 틱에 보상이 들어갑니다. 폭발 파티클과 소리가 납니다.

기본 설정으로 y=64 지형이면 착지까지 약 14초 걸립니다.

### 착지 지점

| 조건                                            | 처리                                  |
| ----------------------------------------------- | ------------------------------------- |
| 가장 높은 블록이 물이나 용암                    | 다시 고름 (`avoid-liquid: true`일 때) |
| 지형이 없는 허공                                | 다시 고름                             |
| 빌드 높이 한계                                  | 다시 고름                             |
| `max-location-attempts`(기본 30)번 안에 못 찾음 | 이번 드랍을 건너뜀 (`drop-skipped`)   |

가장 높은 블록 기준이라 **나무 위나 건물 지붕 위**에도 떨어질 수 있습니다.

### 상자 안 보상

1. `sets-per-drop`개의 세트를 가중치로 뽑습니다. 같은 세트는 다시 뽑지 않습니다.
2. 뽑힌 세트의 아이템을 상자 빈칸에 **무작위 위치**로 넣습니다.
3. 상자 칸(27칸)보다 아이템이 많으면 넘치는 아이템은 들어가지 않습니다.

## 구역 바꾸기

```
/gtsupplydrop zone arena
```

`config.yml`의 `zones` 아래 정의된 구역으로 바꿉니다. `settings.active-zone`이 바뀌고 `config.yml`이 저장됩니다.

## 주의 사항

:::warning

- 떨어진 상자는 **자동으로 사라지지 않습니다.** 아무도 열지 않은 상자가 쌓이니, 필요하면 직접 치우세요.
- 착지 지점에 원래 있던 블록은 상자로 **덮어써집니다.** 상자가 떨어지는 동안 그 자리에 다른 블록을 놓아도
  마찬가지입니다.
- 상자가 떨어지는 도중에 서버를 끄거나 플러그인을 리로드하면, 그 상자는 **착지하지 않고 사라집니다.** 좌표는 이미
  알렸지만 상자는 없게 됩니다.
- 착지 지점을 고를 때 청크를 불러오므로, 구역이 넓고 아직 생성되지 않은 지역이 많으면 드랍할 때 서버가 잠시 멈출 수
  있습니다. :::
