# 보상 세트 만들기

```
/gtsupplydrop loot
```

`gtsupplydrop.admin` 권한이 필요합니다(기본값 OP). 54칸짜리 **세트 목록 GUI**가 열립니다.

## 세트란

**칸 하나가 세트 하나**입니다. 세트에는 아이템을 최대 27칸까지 넣을 수 있고, 세트가 뽑히면 안의 아이템이 **넣은 수량
그대로 전부** 상자에 들어갑니다.

| 예시 세트     | 내용                                 |
| ------------- | ------------------------------------ |
| #1 철 장비    | 철 투구, 철 흉갑, 철 레깅스, 철 부츠 |
| #2 음식       | 스테이크 16개, 황금 사과 2개         |
| #3 다이아몬드 | 다이아몬드 5개                       |

상자 하나에 세트를 `sets-per-drop`개(기본 2)씩 넣습니다. **같은 세트는 한 상자에 두 번 들어가지 않습니다.**

## 세트 목록 GUI

| 클릭                | 동작                                   |
| ------------------- | -------------------------------------- |
| 빈 칸 클릭          | 그 칸에 새 세트 만들기 (세트 편집 GUI) |
| 세트 좌클릭         | 세트 아이템 편집                       |
| 세트 우클릭         | 가중치 입력 (채팅)                     |
| 세트 Shift + 우클릭 | 세트 삭제                              |

아이콘은 세트의 첫 아이템이고, 설명에 세트 내용, 가중치, 확률이 나옵니다. 세트 목록에서는 아이템을 꺼내거나 넣을 수
없습니다.

## 세트 편집 GUI

27칸 GUI에 세트에 넣을 아이템을 자유롭게 넣고 뺍니다. **창을 닫으면 저장**되고 세트 목록으로 돌아갑니다.

- 이름, 인챈트, 설명이 붙은 아이템도 그대로 지급됩니다.
- 모두 비우고 닫으면 세트가 삭제됩니다.
- 새로 만든 세트의 가중치는 1입니다.

:::warning 편집 GUI에 넣은 아이템은 **돌려받을 수 없습니다.** 반대로 편집 GUI를 열어 아이템을 꺼내면 그 아이템을 가질 수
있으므로(복사), 관리자 외에는 이 명령어를 쓰지 못하게 하세요. :::

## 가중치

세트를 우클릭하면 GUI가 닫히고 채팅으로 숫자를 입력합니다.

- 0~1,000,000 사이 정수. `0`이면 추첨에서 빠집니다.
- `취소`를 입력하거나 `input-timeout-seconds`(기본 60초)가 지나면 취소됩니다.
- 숫자를 잘못 입력하면 오류 메시지가 나오고 계속 입력을 기다립니다.

가중치는 다른 세트와의 비율입니다. 세트 3개의 가중치가 `1, 1, 2`면 한 번 뽑을 때 25%, 25%, 50%입니다.

:::note GUI에 나오는 확률은 **한 번 뽑을 때** 확률입니다. 기본 설정처럼 상자에 세트를 2개 넣으면, 첫 번째로 뽑힌 세트를
빼고 두 번째를 다시 뽑습니다. 그래서 가중치가 낮은 세트도 실제로 상자에 들어갈 확률은 GUI에 나온 값보다 높습니다. :::
