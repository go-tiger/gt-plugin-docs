# GTSupplyDrop

정해진 구역에 **보급 상자**가 하늘에서 떨어지는 플러그인입니다. 떨어지기 시작할 때 좌표를 전체에 알리므로, 플레이어들이
먼저 차지하려고 달려가는 이벤트를 만들 수 있습니다.

## 주요 기능

| 기능        | 설명                                                                                         |
| ----------- | -------------------------------------------------------------------------------------------- |
| 정기 드랍   | 정한 주기(기본 10분)마다 자동으로 드랍                                                       |
| 즉시 드랍   | 명령어로 바로 한 번 드랍                                                                     |
| 낙하 연출   | 상자가 하늘에서 천천히 내려오며 파티클과 소리. 착지하면 폭발 효과와 함께 실제 상자로 바뀜    |
| 안전한 위치 | 구역 안에서 무작위로 고르되 물, 용암, 허공은 피함                                            |
| 보상 세트   | GUI로 아이템 묶음(세트)을 만들고 가중치를 정함. 상자마다 서로 다른 세트를 정한 개수만큼 넣음 |
| 여러 구역   | 구역을 여러 개 정의하고 명령어로 바꿈                                                        |
