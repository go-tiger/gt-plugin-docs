# 설치하기

## 요구 사항

| 항목 | 요구 사항                                           |
| ---- | --------------------------------------------------- |
| 서버 | Spigot 1.20.1 이상 (Paper 등 Spigot 호환 서버 포함) |
| Java | 17 이상                                             |

다른 플러그인은 필요 없습니다.

## 설치

1. `GTSupplyDrop-<버전>.jar`를 서버의 `plugins/` 폴더에 넣습니다.
2. 서버를 실행합니다. 다음 파일이 자동으로 생성됩니다.

| 파일                              | 설명                          |
| --------------------------------- | ----------------------------- |
| `plugins/GTSupplyDrop/config.yml` | 주기, 구역, 연출, 메시지 설정 |
| `plugins/GTSupplyDrop/loot.yml`   | 보상 세트. GUI로 편집         |

3. [`config.yml`](./config.md)의 `zones.main`을 서버 맵에 맞게 고칩니다. 기본값은 `world` 월드의 x, z -500~500입니다.
4. [보상 세트 만들기](./loot.md)를 보고 보상을 넣습니다. 보상이 없으면 **빈 상자**가 떨어집니다.
