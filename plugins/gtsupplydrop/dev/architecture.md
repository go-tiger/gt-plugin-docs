# 구조

GTSupplyDrop은 외부에 공개하는 API나 이벤트가 없고, 데이터베이스를 쓰지 않습니다.

## 패키지

| 패키지                     | 역할                                                                                                                   |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `dev.gotiger.gTSupplyDrop` | 메인 클래스. 설정과 구역 로드, 종료 시 연출과 GUI 정리                                                                 |
| `command`                  | `/gtsupplydrop`                                                                                                        |
| `config`                   | 구역(`DropZone`)                                                                                                       |
| `drop`                     | 타이머와 1회 드랍(`DropScheduler`), 착지 지점(`LocationPicker`), 낙하 연출(`FallAnimation`), 상자 채우기(`LootFiller`) |
| `loot`                     | 보상 세트(`LootSet`), `loot.yml` 입출력과 이전 형식 변환(`LootStorage`)                                                |
| `gui`                      | 세트 목록과 세트 편집 GUI, 홀더, 리스너                                                                                |
| `input`                    | 가중치 채팅 입력                                                                                                       |
| `util`                     | 아이템 직렬화, 메시지                                                                                                  |

## 드랍 1회

```
dropOnce()  (타이머 또는 force, 메인 스레드)
  │  활성 구역 확인
  ▼
LocationPicker.pick()
  │  무작위 x, z → getHighestBlockYAt → 허공, 높이 한계, 액체 검사
  │  최대 max-location-attempts번
  ▼
FallAnimation.start()
  │  drop-height에 BlockDisplay(CHEST) 소환, 같은 틱에 좌표 전체 공개
  ▼  매 틱: y -= speed, teleport, 파티클과 소리
land()
  │  디스플레이 제거 → setType(CHEST) → 같은 틱에 LootFiller.fill()
  ▼  착지 효과
```

- 디스플레이는 블록 모서리 기준으로 그려지므로 정수 좌표에 두면 설치될 상자와 정확히 겹칩니다.
- 디스플레이는 `setPersistent(false)`라 청크와 함께 저장되지 않습니다. 청크가 언로드되어 디스플레이가 사라져도 착지는
  그대로 진행합니다.
- 상자 설치와 보상 채우기 사이에 틱 간격이 없어서, 빈 상자가 보이는 순간이 없습니다.
- 진행 중인 연출은 `activeAnimations`에 모아 두고, `onDisable`에서 모두 중단해 디스플레이를 지웁니다. 이때 상자는
  설치하지 않습니다.
- 정기 타이머는 메모리에만 있어서 재시작하면 사라집니다.

## 보상 추첨

`LootFiller.fill()`:

1. 가중치 1 이상인 세트를 후보로 모읍니다.
2. `sets-per-drop`번 반복합니다. 매번 가중치 누적합으로 하나를 뽑고 후보에서 뺍니다(비복원 추첨).
3. 뽑힌 세트들의 아이템을 모아, 상자 빈칸을 섞은 순서대로 넣습니다.
4. 빈칸이 모자라면 남는 아이템은 버리고 경고 로그를 남깁니다.

추첨 방식은 GTRandomBox와 같습니다(`roll = 1 ~ 가중치 합`, 누적합 비교).

## GUI

| GUI                    | 크기 | 동작                                                          |
| ---------------------- | ---- | ------------------------------------------------------------- |
| 세트 목록 (`SETS`)     | 54칸 | 클릭과 드래그를 항상 취소. 아이콘은 세트 첫 아이템의 복제본   |
| 세트 편집 (`SET_EDIT`) | 27칸 | 자유 편집. 닫을 때 27칸을 저장하고 1틱 뒤 세트 목록을 다시 엶 |

서버 종료나 리로드로 편집 GUI가 강제로 닫히는 경우에도 `onDisable`에서 먼저 저장합니다.

## 채팅 입력

`AsyncPlayerChatEvent`(LOW)를 취소해 가로챕니다. 비동기 이벤트라 저장과 GUI 재오픈은 메인 스레드로 넘깁니다. 대기
상태마다 새 `PendingInput` 객체를 만들어서, 시간 초과 작업이 자기가 건 대기만 취소하게 합니다.
