# GTStorage

플레이어마다 **개인 창고**를 제공하는 플러그인입니다. 어디서든 `/창고`로 열 수 있고, 내용은 서버에 저장됩니다.

## 주요 기능

| 기능               | 설명                                                                       |
| ------------------ | -------------------------------------------------------------------------- |
| 개인 창고          | `/창고`로 어디서든 열기. 최대 6줄(54칸)                                    |
| 플레이어별 크기    | 관리자가 플레이어마다 줄 수를 따로 지정                                    |
| 아이템 그대로 보존 | 인챈트, 이름, 설명, 셜커 상자 내용물까지 그대로 저장                       |
| 유실 방지          | 창 닫기, 접속 종료, 서버 종료 시 저장. 열어 둔 창고도 주기적으로 자동 저장 |
| 보관 금지 아이템   | 지정한 아이템은 창고에 넣을 수 없음                                        |
| 관리자 열람        | 다른 플레이어의 창고를 열어 보고 수정 (오프라인 포함)                      |
