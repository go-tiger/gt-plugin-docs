# 명령어

## 플레이어

| 명령어  | 권한            | 설명         |
| ------- | --------------- | ------------ |
| `/창고` | `gtstorage.use` | 내 창고 열기 |

`/storage`, `/gtstorage`로도 쓸 수 있습니다. `gtstorage.use`는 기본으로 모든 플레이어에게 있습니다.

## 관리자

`gtstorage.admin` 권한이 필요합니다. 기본값은 OP입니다. `/창고관리`로도 쓸 수 있습니다.

| 명령어                                   | 설명                                   |
| ---------------------------------------- | -------------------------------------- |
| `/gtstorageadmin open <닉네임>`          | 다른 플레이어의 창고 열기 (플레이어만) |
| `/gtstorageadmin setrows <닉네임> <1~6>` | 플레이어의 창고 줄 수 변경             |
| `/gtstorageadmin reload`                 | `config.yml` 다시 불러오기             |

## 규칙

- **한 창고는 한 명만**: 같은 창고를 두 사람이 동시에 열 수 없습니다. 주인이 열고 있으면 관리자도 열 수 없고, 반대도
  마찬가지입니다. 이때는 `storage-busy` 메시지가 나옵니다. 창을 닫은 직후 저장하는 동안에도 잠깐 열리지 않습니다.
- **오프라인 플레이어**: `open`과 `setrows`는 서버에 한 번이라도 접속한 플레이어라면 오프라인이어도 됩니다.
- **줄 수 줄이기**: `setrows`로 줄 수를 줄일 때, 없어질 칸에 아이템이 있으면 `rows-shrink-blocked` 메시지와 함께
  거부됩니다. 먼저 `open`으로 아이템을 옮기세요. 창고가 열려 있을 때도 변경할 수 없습니다.
- **커서에 든 아이템**: 아이템을 집은 채로 창을 닫거나 접속을 끊으면 내 인벤토리로 돌아옵니다. 인벤토리가 가득 차 있으면
  발밑에 떨어집니다.

## 보관 금지 아이템

`blocked-items`에 있는 아이템은 클릭, 쉬프트 클릭, 숫자 키, 드래그 중 어떤 방법으로도 창고에 넣을 수 없습니다. 넣으려고
하면 `item-blocked` 메시지가 나옵니다.

:::note

- 셜커 상자 같은 **용기 안에 든 금지 아이템**은 막지 않습니다.
- 금지 목록에 추가하기 전부터 창고에 있던 아이템은 그대로 남습니다. 꺼낼 수는 있지만 다시 넣을 수는 없습니다. :::
