# 명령어

모든 명령어는 `gtdebt.admin` 권한이 필요합니다. 기본값은 OP입니다.

## 개별 명령어

Skript에서 `execute console command`로 호출하기 쉽도록 한글 명령어를 따로 제공합니다.

| 명령어                    | 설명                                          |
| ------------------------- | --------------------------------------------- |
| `/빚조회 <닉네임>`        | 빚 잔액 조회                                  |
| `/빚증가 <닉네임> <금액>` | 빚을 금액만큼 증가 (상한 없음)                |
| `/빚감소 <닉네임> <금액>` | 빚을 금액만큼 감소 (0원 아래로 내려가지 않음) |
| `/빚설정 <닉네임> <금액>` | 빚을 금액으로 직접 설정 (0원 가능)            |

## 통합 명령어

| 명령어                         | 설명                       |
| ------------------------------ | -------------------------- |
| `/gtdebt 조회 <닉네임>`        | `/빚조회`와 같음           |
| `/gtdebt 증가 <닉네임> <금액>` | `/빚증가`와 같음           |
| `/gtdebt 감소 <닉네임> <금액>` | `/빚감소`와 같음           |
| `/gtdebt 설정 <닉네임> <금액>` | `/빚설정`과 같음           |
| `/gtdebt reload`               | `config.yml` 다시 불러오기 |

## 규칙

- **대상 플레이어**: 접속 중이 아니어도 됩니다. 단, 서버에 **한 번도 접속한 적 없는 닉네임**은 `player-not-found`
  메시지로 거부됩니다.
- **금액**: 정수만 받습니다. 증가와 감소는 1 이상, 설정은 0 이상이어야 합니다. 쉼표(`1,000`)는 쓸 수 없습니다.
- **감소**: 빚보다 큰 금액을 감소시키면 0원이 됩니다. 이미 0원인 플레이어에게 감소를 실행하면 `debt-already-cleared`
  메시지가 나오고 아무것도 바뀌지 않습니다.
- **완납**: 증가, 감소, 설정 중 어떤 방법으로든 빚이 0원보다 많은 상태에서 0원이 되면 완납 처리됩니다. 다시 빚이
  생겼다가 0원이 되면 완납이 또 일어납니다.

## 완납 연출

빚이 0원이 되면 다음이 실행됩니다.

1. 대상 플레이어가 접속 중이면 타이틀(`cleared-title`, `cleared-subtitle`)을 보여 줍니다.
2. 서버 전체에 `cleared-chat` 메시지를 보냅니다. 플레이어가 오프라인이면 1번과 2번 모두 생략됩니다.
3. 다른 플러그인을 위해 [`DebtClearedEvent`](../dev/api.md#debtclearedevent)를 발생시킵니다.

## Skript 예시

```text
command /갚기 <integer>:
    trigger:
        execute console command "빚감소 %player% %arg-1%"
```
