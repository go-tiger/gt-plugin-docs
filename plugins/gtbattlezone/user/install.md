# 설치하기

## 요구 사항

| 항목 | 요구 사항                                           |
| ---- | --------------------------------------------------- |
| 서버 | Spigot 1.20.1 이상 (Paper 등 Spigot 호환 서버 포함) |
| Java | 17 이상                                             |

다른 플러그인은 필요 없습니다.

## 설치

1. `GTBattleZone-<버전>.jar`를 서버의 `plugins/` 폴더에 넣습니다.
2. 서버를 실행하면 `plugins/GTBattleZone/config.yml`이 생성됩니다. 데이터 파일은 따로 없습니다.
3. 게임 맵 한가운데에 서서 `/gtbattlezone center`로 중심을 지정합니다. 중심이 없으면 `start`할 수 없습니다.
4. 필요하면 [`config.yml`](./config.md)의 `phases`를 맵 크기에 맞게 고칩니다.
