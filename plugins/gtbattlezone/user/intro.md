# GTBattleZone

배틀로얄의 **자기장**을 만드는 플러그인입니다. 바닐라 월드보더를 단계별로 줄이고, 자기장 밖에 있는 플레이어에게 피해를
줍니다.

## 주요 기능

| 기능             | 설명                                                            |
| ---------------- | --------------------------------------------------------------- |
| 단계별 축소      | 크기, 유지 시간, 줄어드는 시간을 단계마다 설정                  |
| 자기장 중심      | 서 있는 자리나 좌표로 지정                                      |
| 자기장 밖 피해   | 일정 주기마다 고정 피해. 바닐라 보더 피해 방식도 선택 가능      |
| 강제 축소        | 유지 시간을 기다리지 않고 바로 다음 단계로                      |
| 상태 확인        | 현재 단계, 크기, 다음 전환까지 남은 시간                        |
| 최종 단계 이벤트 | 마지막 단계에 도달하면 다른 플러그인이 받을 수 있는 이벤트 발생 |

우승 판정, 플레이어 탈락, 게임 시작 텔레포트 같은 기능은 없습니다. 자기장만 담당하고, 나머지는 다른 플러그인이나
Skript로 처리합니다.
