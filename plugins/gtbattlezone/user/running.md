# 게임 진행

모든 명령어는 `gtbattlezone.admin` 권한이 필요합니다(기본값 OP). `/자기장`으로도 쓸 수 있습니다.

## 1. 중심 지정

```
/gtbattlezone center                     # 내가 서 있는 x, z (내 월드)
/gtbattlezone center world_battle        # 내가 서 있는 x, z, 월드는 world_battle
/gtbattlezone center world_battle 0 0    # 좌표 직접 지정 (콘솔 가능)
```

- 좌표는 소수 첫째 자리까지 저장됩니다.
- `config.yml`의 `state`에 저장되므로 재시작해도 유지됩니다.
- 진행 중이 아닐 때 지정하면 월드보더 중심도 바로 옮깁니다.
- 진행 중에 지정하면 **다음 축소가 시작될 때** 새 중심이 적용됩니다. 진행 중에는 다른 월드로 옮길 수 없습니다.

## 2. 시작

```
/gtbattlezone start
```

1. 월드보더 중심을 지정한 중심으로 맞춥니다.
2. 보더 경고 거리, 경고 시간, 피해 방식을 적용합니다.
3. **1단계 크기로 보더를 바로 맞춥니다.** 보더 밖에 있던 플레이어는 그 순간 자기장 밖이 됩니다.
4. 시작 메시지를 전체에 알립니다.

## 3. 단계 진행

단계는 `phases`에 적은 순서대로 진행됩니다.

```
1단계 크기 2000 ─ 300초 유지 ─ 60초 동안 줄어듦 ─▶ 2단계 크기 1000 ─ 240초 유지 ─ 60초 동안 줄어듦 ─▶ ...
```

- 각 단계는 `duration-seconds` 동안 유지된 뒤, `shrink-seconds` 동안 다음 단계 크기로 줄어듭니다.
- 줄어들기 시작할 때 `phase-advanced` 메시지를 전체에 알립니다.
- 줄어드는 동작은 바닐라 월드보더가 처리하므로 매끄럽게 움직입니다.
- 마지막 단계까지 줄어들면 `final-phase` 메시지를 알리고 진행을 멈춥니다. 다른 플러그인을 위해
  [최종 단계 이벤트](../dev/api.md)가 발생합니다.

기본 설정으로는 시작부터 최종 단계까지 약 17분 15초 걸립니다.

## 자기장 밖 피해

`damage-check-interval-seconds`(기본 2초)마다 확인해서, 자기장 밖에 있는 플레이어에게 `damage-per-tick`(기본 2, 하트
1개)만큼 피해를 주고 액션바에 `자기장 밖입니다!`를 띄웁니다.

- 자기장은 **정사각형**입니다. 원형 거리가 아니라 x, z를 각각 비교합니다.
- 줄어드는 도중에는 그 순간의 보더 크기로 판정합니다.
- 관전 모드 플레이어와 `gtbattlezone.bypass` 권한이 있는 플레이어는 피해를 받지 않습니다. 관리자도 이 권한이 없으면
  피해를 받습니다.
- 자기장이 진행 중인 월드의 플레이어만 대상입니다.

`use-vanilla-border-damage: true`로 바꾸면 이 판정 대신 바닐라 월드보더 피해를 씁니다. 자세한 내용은
[설정](./config.md#피해-방식)을 참고하세요.

## 강제 축소

```
/gtbattlezone shrink
```

남은 유지 시간을 건너뛰고 바로 다음 단계로 줄이기 시작합니다. 이미 줄어드는 중이거나 최종 단계면 안 됩니다.

## 상태 확인

```
/gtbattlezone status
```

| 항목           | 내용                               |
| -------------- | ---------------------------------- |
| 중심           | 월드, x, z                         |
| 단계           | 현재 단계 / 전체 단계 수           |
| 현재/목표 크기 | 지금 보더 크기 / 이번 단계 크기    |
| 축소 완료까지  | 줄어드는 중일 때만                 |
| 다음 전환까지  | 다음 축소가 시작되기까지 남은 시간 |

## 4. 중단과 초기화

```
/gtbattlezone stop     # 진행만 멈춤. 보더는 지금 크기 그대로
/gtbattlezone reset    # 진행을 멈추고 보더를 바닐라 기본값으로
```

- `stop`하면 줄어드는 중이었어도 그 자리에서 멈춥니다. 피해 판정도 멈춥니다.
- `reset`은 보더를 바닐라 기본 크기(사실상 보더 없음)로 되돌립니다. 대상은 진행 중인 월드, 없으면 중심 월드, 그것도
  없으면 실행한 사람의 월드입니다.
- 게임이 끝나면 `reset`으로 보더를 정리하세요.

:::warning **진행 중에 서버를 재시작하거나 플러그인을 리로드하면 진행 상태가 사라집니다.** 월드보더는 그 상태
그대로(줄어드는 중이었다면 계속 줄어듦) 남지만, 플러그인은 진행 중이 아닌 것으로 보고 자기장 밖 피해를 주지 않습니다. 이
경우 `reset` 후 다시 `start`해야 합니다. :::
