# 등급과 풀 만들기

모든 명령어는 `gtlootchest.admin` 권한이 필요합니다(기본값 OP). `/전리품`으로도 쓸 수 있습니다.

## 개념

```
등급 (예: rare)
 ├─ 랜덤 풀 (random)      ── 가중치로 random-count개 추첨
 │   ├─ 세트 #1  가중치 10   [다이아몬드 3개]
 │   └─ 세트 #2  가중치 30   [철 주괴 10개, 금 주괴 5개]
 └─ 보장 풀 (guaranteed)  ── 무작위로 guaranteed-count개, 가중치 무시
     └─ 세트 #1             [빵 8개]
```

- **세트**: 아이템 묶음입니다. 세트 하나에 최대 27칸까지 넣을 수 있고, 뽑히면 안의 아이템이 넣은 수량 그대로 모두
  들어갑니다.
- **랜덤 풀**: 세트마다 가중치가 있고, 가중치 비율로 추첨합니다.
- **보장 풀**: 가중치 없이 똑같은 확률로 뽑습니다. "등급마다 꼭 들어가야 하는 것"에 씁니다.

상자를 채울 때 보장 풀 결과를 먼저 넣고 랜덤 풀 결과를 넣습니다. 상자 칸이 모자라면 랜덤 풀 아이템이 먼저 빠집니다.

## 1. 등급 만들기

```
/gtlootchest tier create rare
```

- 이름은 32자 이하의 글자, 숫자, `-`, `_`만 쓸 수 있습니다. `chests`는 쓸 수 없습니다.
- 대소문자를 구분하지 않습니다(`Rare`와 `rare`는 같은 등급).
- `tiers/rare.yml`이 만들어집니다. 처음 뽑을 개수는 랜덤 3개, 보장 0개입니다.

## 2. 세트 넣기

```
/gtlootchest tier pool rare              # 랜덤 풀
/gtlootchest tier pool rare guaranteed   # 보장 풀
/gtlootchest tier manage rare            # 랜덤 풀 (pool rare 와 같음)
```

54칸 **세트 목록 GUI**가 열립니다. 칸 하나가 세트 하나입니다.

| 클릭                | 동작                    |
| ------------------- | ----------------------- |
| 빈 칸 클릭          | 그 칸에 새 세트 만들기  |
| 세트 좌클릭         | 세트 아이템 편집        |
| 세트 우클릭         | 가중치 입력 (랜덤 풀만) |
| 세트 Shift + 우클릭 | 세트 삭제               |

**세트 편집 GUI**(27칸)에 아이템을 넣고 창을 닫으면 저장되고 목록으로 돌아갑니다. 모두 비우고 닫으면 세트가 삭제됩니다.

- 새로 만든 랜덤 풀 세트의 가중치는 `default-weight`(기본 10)입니다.
- 이름, 인챈트, 설명이 붙은 아이템도 그대로 들어갑니다.

:::warning 편집 GUI에 넣은 아이템은 돌려받을 수 없습니다. 반대로 편집 GUI에서 아이템을 꺼내면 그 아이템을 가질 수
있으므로(복사), 관리자 외에는 이 명령어를 쓰지 못하게 하세요. :::

## 3. 가중치 (랜덤 풀)

세트를 우클릭하면 GUI가 닫히고 채팅으로 숫자를 입력합니다.

- 0~`max-weight`(기본 1,000,000) 사이 정수. `0`이면 추첨에서 빠집니다.
- `취소`를 입력하거나 `input-timeout-seconds`(기본 60초)가 지나면 취소됩니다.
- 입력이 끝나면 세트 목록이 다시 열립니다.

세트 목록 아이콘의 설명에 가중치와 한 번 뽑을 때의 확률이 나옵니다.

## 4. 뽑을 개수 정하기

뽑을 개수는 명령어가 없고 `tiers/<등급>.yml`을 직접 고칩니다.

```yaml
random-count:
  min: 2
  max: 4
guaranteed-count:
  min: 1
  max: 1
```

- 상자마다 min~max 사이에서 무작위로 개수를 정합니다.
- min이 max보다 크면 max를 min에 맞춥니다.
- 고친 뒤에는 `/gtlootchest reload`를 실행하세요.

### 중복

| 풀      | 설정                            | 기본값                                |
| ------- | ------------------------------- | ------------------------------------- |
| 랜덤 풀 | `allow-duplicate-in-draw`       | `false` (한 상자에 같은 세트 한 번만) |
| 보장 풀 | `allow-duplicate-in-guaranteed` | `true`                                |

중복을 허용하지 않아도, 풀의 세트 수가 뽑을 개수보다 적으면 그 상자는 중복을 허용해서 뽑고 로그를 남깁니다.

## 등급 확인과 삭제

```
/gtlootchest tier list
/gtlootchest tier info rare
/gtlootchest tier delete rare
```

- `info`는 두 풀의 세트 수, 뽑을 개수, 이 등급을 쓰는 상자와 과녁 수를 보여 줍니다. 보장 풀이 비어 있으면 경고가
  나옵니다.
- 이 등급으로 채운 상자가 있으면 `delete`가 한 번 경고하고, **같은 명령어를 다시 입력**하면 삭제합니다. 그 상자 기록은
  "미지정"이 됩니다.
- 이 등급의 과녁이 남아 있으면 `start`할 때 그 과녁은 건너뜁니다.
