# 상자 배치와 진행

## 두 가지 모드

| 모드          | 과녁 자리의 블록    | 할 수 있는 일                 |
| ------------- | ------------------- | ----------------------------- |
| **배치 모드** | 과녁(`TARGET`)      | 과녁 설치, 제거               |
| **상자 모드** | 상자 또는 함정 상자 | 플레이어가 상자를 열어 가져감 |

모드는 서버 전체에 하나입니다. 처음에는 배치 모드입니다.

## 1. 과녁 받기

```
/gtlootchest give rare             # 나에게 1개
/gtlootchest give rare 64          # 나에게 64개
/gtlootchest give rare 64 Steve    # Steve에게 64개
```

- 순서는 **등급, 개수, 닉네임**입니다. 개수는 1~2304.
- 과녁에는 등급이 들어 있습니다(`전리품 과녁 - rare`). 이 명령어로 받은 과녁만 인정되고, 일반 과녁 블록은 상관없습니다.

## 2. 배치 모드에서 설치

상자가 생기길 원하는 자리에 과녁을 설치합니다.

- 상자 모드에서는 설치할 수 없습니다(`marker-place-active`).
- 등급이 삭제된 과녁은 설치할 수 없습니다.
- 잘못 놓은 과녁은 부수면 기록이 지워지고 과녁 아이템이 떨어집니다(크리에이티브 모드에서는 안 떨어짐).
- 배치 모드에서 과녁은 폭발과 피스톤으로부터 보호됩니다.

:::warning 배치 모드에서는 **권한과 상관없이 누구나** 과녁을 부수고 과녁 아이템을 가져갈 수 있습니다. 플레이어가 들어올
수 없는 상태에서 배치하세요. :::

## 3. 상자 모드로 전환

```
/gtlootchest start
```

1. 전체 과녁 중 `trap-percent`(기본 10%)를 무작위로 골라 **함정**으로 정합니다(반올림).
2. 과녁을 하나씩 상자로 바꿉니다. 함정은 **덫 상자**(`TRAPPED_CHEST`), 나머지는 일반 상자입니다.
3. 상자마다 그 등급의 보장 풀과 랜덤 풀에서 뽑아 빈칸에 무작위로 넣습니다.
4. 끝나면 `상자 n개, 함정 지정 n개, 건너뜀 n개`가 나옵니다.

- 한 틱에 `markers-per-tick`(기본 20)개씩 나눠 바꿉니다. 그동안은 다른 전환 명령어와 `reload`가 막힙니다(`marker-busy`).
- 과녁 자리에 다른 블록이 있거나 등급이 없으면 건너뜁니다.
- 뽑힌 아이템이 없으면 빈 상자가 됩니다.

## 함정 상자

함정 상자를 열면 **독**에 걸립니다.

- 독 지속 시간은 **현재 체력의 절반**이 깎이는 만큼입니다. 독은 체력을 1 아래로 내리지 않으므로 함정으로 죽지는
  않습니다.
- 이미 독에 걸려 있으면 다시 걸리지 않습니다.
- 크리에이티브, 관전 모드에서는 걸리지 않습니다.
- 덫 상자는 열면 레드스톤 신호도 냅니다(바닐라 동작).

:::note 덫 상자는 걸쇠가 빨간색이라 일반 상자와 겉모습이 다릅니다. 눈치 빠른 플레이어는 열기 전에 알아챌 수 있습니다.
:::

## 4. 배치 모드로 돌아가기

```
/gtlootchest stop       # 상자를 과녁으로 되돌림
/gtlootchest restart    # 되돌린 뒤 바로 다시 start (함정과 아이템 새로 뽑기)
```

- 상자에 남은 아이템은 **지워지고** 과녁으로 바뀝니다. 바닥에 떨어지지 않습니다.
- 플레이어가 상자를 부숴 빈자리가 됐으면 과녁을 다시 놓습니다.
- 그 자리에 다른 블록이 있으면 덮어쓰지 않고 건너뜁니다.

`restart`는 다음 판을 시작할 때 씁니다.

## 바라보는 상자 바로 채우기

과녁과 상관없이, 바라보는 상자를 지금 바로 채웁니다.

```
/gtlootchest chest set rare          # 빈 상자만
/gtlootchest chest set rare force    # 내용물이 있어도 그 위에 채움
/gtlootchest chest info              # 이 상자의 등급과 채운 시각
```

- 비어 있지 않은 상자는 `force` 없이 채우지 않습니다. `force`는 기존 아이템을 지우지 않고 빈칸에 더 넣습니다.
- 뽑힌 아이템이 하나도 없으면 상자를 건드리지 않습니다.
- 칸이 모자라 못 넣은 아이템 수가 나오고, 무엇이 빠졌는지 콘솔에 남습니다.
- 채운 상자는 `tiers/chests.yml`에 기록됩니다. 상자가 없어져도 기록은 자동으로 지워지지 않습니다.
