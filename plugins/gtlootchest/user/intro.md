# GTLootChest

맵 곳곳에 **등급별 전리품 상자**를 깔아 두는 플러그인입니다. 관리자가 상자 자리에 과녁 블록을 설치해 두고 `start`하면,
과녁이 한꺼번에 상자로 바뀌며 등급에 맞는 아이템이 채워집니다. 일부는 독이 걸린 함정 상자가 됩니다.

## 주요 기능

| 기능         | 설명                                                                  |
| ------------ | --------------------------------------------------------------------- |
| 등급         | "일반", "희귀"처럼 등급을 만들고 등급마다 들어갈 아이템을 따로 설정   |
| 두 종류의 풀 | **랜덤 풀**(가중치로 추첨)과 **보장 풀**(무조건 몇 개 들어감)         |
| 세트         | 아이템 묶음 단위로 뽑음. 세트 하나에 여러 아이템                      |
| 과녁 배치    | 과녁을 설치한 자리가 `start` 때 상자로 바뀜. 수백 개도 틱을 나눠 처리 |
| 함정 상자    | `start` 때 일부를 함정으로 지정. 열면 독에 걸림                       |
| 바로 채우기  | 바라보는 상자를 명령어로 바로 채우기                                  |
