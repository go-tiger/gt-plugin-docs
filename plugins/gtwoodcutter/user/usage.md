# 사용 방법

## 인챈트 얻기

다음 중 한 가지 방법으로 도끼에 벌목 인챈트를 붙입니다.

- 마법부여대에서 도끼에 인챈트
- 모루로 벌목 인챈트 책 합치기
- 관리자가 `/gtwoodcutter give` 실행

## 벌목하기

벌목 인챈트가 붙은 도끼로 나무의 **밑동**(맨 아래 원목)을 캐면, 그 나무의 원목과 잎이 한 번에 수확됩니다.

- 밑동이 아닌 중간 원목을 캐면 그 블록 하나만 부서집니다.
- 짙은 참나무와 큰 정글나무처럼 밑동이 2x2인 나무는 네 칸 중 아무거나 캐도 됩니다.
- 수확한 아이템은 밑동 위치에 떨어집니다. `direct-to-inventory`를 켜면 인벤토리로 바로 들어옵니다.
- 수확 후 `replant.delay-ticks`(기본 1초) 뒤에 밑동 자리에 묘목이 다시 심어집니다.

## 발동 조건

다음 조건을 모두 만족해야 발동합니다.

| 조건                                         | 관련 설정                                |
| -------------------------------------------- | ---------------------------------------- |
| 기능이 켜진 월드                             | `enabled-worlds`                         |
| `gtwoodcutter.use` 권한 (기본 모든 플레이어) |                                          |
| 자동 벌목을 끄지 않음                        | `/gtwoodcutter toggle`                   |
| 웅크림 조건 만족                             | `sneak-mode`                             |
| 허용된 도구                                  | `allowed-tools`                          |
| 벌목 인챈트가 붙어 있음                      |                                          |
| 켜진 나무 종류의 밑동                        | `trees`                                  |
| 나무 크기가 상한 이하                        | `max-blocks`, `max-radius`, `max-height` |
| 잎이 붙어 있음                               | `require-leaves`                         |

나무가 `max-blocks`보다 크면 `tree-too-large` 메시지가 나오고, 캔 블록 하나만 부서집니다.

## 나무로 보는 범위

- 캔 밑동에서 시작해 같은 종류의 원목과 잎을 대각선 방향까지 따라가며 찾습니다.
- 밑동보다 아래, 밑동에서 `max-height`보다 위, 수평으로 `max-radius`보다 먼 블록은 찾지 않습니다.
- 다른 종류의 원목이나 다른 블록을 만나면 그 방향으로는 더 찾지 않습니다.
- 진홍빛, 뒤틀린 나무는 사마귀 블록을 잎으로 봅니다.

:::warning 같은 종류의 나무가 서로 붙어 있으면 잎을 타고 이어져서 **옆 나무까지 함께 수확**될 수 있습니다. 잎이 붙어
있는 원목 건축물 근처에서는 `/gtwoodcutter toggle`로 꺼 두세요. :::

## 내구도

- 원목 1개당 `durability-per-block`만큼 내구도가 닳습니다. 잎은 닳지 않습니다.
- 내구성 인챈트가 있으면 바닐라처럼 확률적으로 덜 닳습니다.
- 수확 중에 도끼가 부서질 만큼 내구도가 부족하면 가능한 만큼만 캐고 멈춥니다. 도끼가 부서지면 `tool-broken` 메시지가
  나옵니다.
- `prevent-tool-break: true`이면 내구도가 원목 수보다 부족할 때 아예 발동하지 않습니다.

## 자동 벌목 끄기

```
/gtwoodcutter toggle
```

다시 실행하면 켜집니다. 이 설정은 저장되지 않아 **서버를 재시작하면 다시 켜집니다.**
