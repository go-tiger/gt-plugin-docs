# GTWoodcutter

**벌목 인챈트**가 붙은 도끼로 나무 밑동을 캐면 나무 전체를 한 번에 수확하는 플러그인입니다.

## 주요 기능

| 기능           | 설명                                                                                                                  |
| -------------- | --------------------------------------------------------------------------------------------------------------------- |
| 한 번에 벌목   | 밑동을 캐면 연결된 원목과 잎을 모두 수확                                                                              |
| 바닐라 인챈트  | 데이터팩으로 등록한 진짜 인챈트. 마법부여대와 모루에서도 얻을 수 있음                                                 |
| 나무 종류      | 참나무, 자작나무, 가문비나무, 정글, 아카시아, 짙은 참나무, 맹그로브, 벚나무, 진홍빛, 뒤틀린 나무 (종류별로 켜고 끄기) |
| 건축물 보호    | 잎이 없는 원목 구조물은 나무로 보지 않음. 플레이어가 설치한 원목 제외 옵션                                            |
| 자동 묘목 심기 | 수확 후 밑동 자리에 묘목을 다시 심음                                                                                  |
| 내구도 소모    | 원목 수만큼 도끼 내구도 소모. 내구성 인챈트 반영                                                                      |
| 지역 보호 연동 | WorldGuard 등이 파괴를 막은 블록은 수확하지 않음                                                                      |
