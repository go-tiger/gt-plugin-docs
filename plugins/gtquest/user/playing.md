# 퀘스트 진행하기

## GUI 열기

| 방법                                | 표시되는 퀘스트          |
| ----------------------------------- | ------------------------ |
| `/퀘스트` 또는 `/gtquest`           | 전체 퀘스트              |
| 퀘스트가 연결된 Citizens NPC 우클릭 | 그 NPC에 연결된 퀘스트만 |

GUI는 한 화면에 최대 54개까지 표시합니다. 페이지 넘김은 없어서, 그보다 많은 퀘스트는 보이지 않습니다.

## 조작

| 클릭            | 동작                             |
| --------------- | -------------------------------- |
| 좌클릭          | 수락 (포기한 퀘스트는 다시 수락) |
| 우클릭          | 포기                             |
| 쉬프트 + 좌클릭 | 납품                             |

## 퀘스트 상태

| 상태                  | 아이콘             | 설명                            |
| --------------------- | ------------------ | ------------------------------- |
| 수락 가능             | 퀘스트 표시 아이템 | 좌클릭으로 수락                 |
| 수락 가능 (이전 포기) | 퀘스트 표시 아이템 | 포기했던 퀘스트. 다시 수락 가능 |
| 진행 중               | 퀘스트 표시 아이템 | 목표 아이템을 모으는 중         |
| 완료                  | 연두색 색유리판    | 다시 할 수 없음                 |
| 잠김                  | 방벽               | 선행 퀘스트를 먼저 완료해야 함  |

아이콘의 설명(로어)에 퀘스트 설명, 상태, 납품 목표, 보상, 조작 안내가 나옵니다.

## 납품

진행 중인 퀘스트는 로어에 목표 아이템별로 `보유 수량/필요 수량`이 표시됩니다. 모두 모이면 숫자가 초록색으로 바뀌고
`쉬프트+좌클릭: 납품` 안내가 나옵니다.

- 목표 아이템을 **모두** 가지고 있어야 납품됩니다. 일부만 가지고 있을 때는 아무것도 가져가지 않습니다.
- 납품하면 목표 수량만큼만 인벤토리에서 빠지고, 보상을 받고, 퀘스트가 완료됩니다.
- 아이템은 이름, 인챈트, 내구도, 커스텀 모델 데이터까지 **완전히 같아야** 인정됩니다. 예를 들어 이름을 바꾼 다이아몬드는
  그냥 다이아몬드 목표로 인정되지 않습니다.
- 진행도는 따로 저장하지 않고 그때그때 인벤토리를 확인합니다. 아이템을 잃어버려도 퀘스트는 진행 중으로 남습니다.

## 보상

| 보상   | 설명                                           |
| ------ | ---------------------------------------------- |
| 경험치 | 경험치 포인트로 지급 (레벨이 아님)             |
| 돈     | Vault 경제 플러그인이 있을 때만 지급           |
| 아이템 | 인벤토리에 넣고, 자리가 없으면 발밑에 떨어뜨림 |
