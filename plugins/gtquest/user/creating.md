# 퀘스트 만들기

모든 관리 명령어는 `gtquest.admin` 권한이 필요합니다(기본값 OP). 퀘스트는 숫자 **ID**로 구분합니다.

## 1. 퀘스트 생성

```
/gtquest create 광부의 부탁
```

`퀘스트를 생성했습니다. (ID: 1, 이름: 광부의 부탁)`처럼 ID가 나옵니다. 이후 명령어에 이 ID를 씁니다.

## 2. 기본 정보 설정

```
/gtquest set 1 desc 광산에서 석탄을 모아 와 줘\n보상은 넉넉히 줄게
/gtquest set 1 material COAL
/gtquest set 1 exp 100
/gtquest set 1 money 5000
```

- 설명의 `\n`은 줄바꿈이 됩니다.
- `material`은 GUI 아이콘으로 쓸 아이템입니다. 기본값은 책(`BOOK`)입니다.
- `exp`는 경험치 포인트, `money`는 돈입니다. 음수는 0으로 저장됩니다.

## 3. 납품 목표 설정

```
/gtquest objectives 1
```

상자 GUI가 열립니다. 목표로 할 아이템을 원하는 수량만큼 넣고 창을 닫으면 저장됩니다.

- 같은 아이템은 수량이 합쳐집니다. 석탄 64개를 두 칸에 넣으면 "석탄 128개" 하나가 됩니다.
- 넣은 아이템과 이름, 인챈트 등이 **완전히 같은** 아이템만 인정됩니다. 일반 아이템을 목표로 하려면 이름이나 인챈트가
  없는 아이템을 넣으세요.
- 목표가 하나도 없는 퀘스트는 납품할 수 없어 완료할 수 없습니다.

:::warning GUI에 넣은 아이템은 **돌려받을 수 없습니다.** 창을 닫으면 설정으로 저장되고 아이템은 사라집니다. 창을 다시
열면 저장된 설정을 보여 주는 사본이 채워져 있고, 이것도 꺼내 가질 수 없습니다. 넣을 아이템은 미리 복사해 두세요. :::

## 4. 보상 아이템 설정

```
/gtquest rewards 1
```

납품 목표와 같은 방식입니다. 보상으로 줄 아이템을 넣고 창을 닫습니다.

## 5. 선행 퀘스트 (선택)

```
/gtquest set 2 prereq 1      # 2번은 1번을 완료해야 수락 가능
/gtquest set 2 prereq none   # 해제
```

선행 퀘스트는 하나만 지정할 수 있습니다. 선행 퀘스트를 삭제하면 연결이 자동으로 풀립니다.

## 6. NPC 연결 (선택)

Citizens NPC의 ID는 NPC를 선택하고 `/npc` 또는 `/npc list`로 확인합니다.

```
/gtquest set 1 npc 3      # 3번 NPC에 연결
/gtquest set 1 npc none   # 해제
```

한 NPC에 여러 퀘스트를 연결할 수 있고, 퀘스트 하나는 NPC 하나에만 연결됩니다. 퀘스트가 연결되지 않은 NPC는 GTQuest가
관여하지 않습니다.

## 7. 목표 아이템 이름 숨기기 (선택)

```
/gtquest set 1 hideobjectives on
```

GUI에서 납품 목표의 아이템 이름이 `???`로 나옵니다. 수량은 그대로 보입니다. 플레이어가 무엇을 모아야 하는지 직접
알아내게 할 때 씁니다.

## 확인

```
/gtquest list
/gtquest info 1
```
