# 명령어

`/퀘스트`로도 쓸 수 있습니다.

## 플레이어

| 명령어     | 권한          | 설명            |
| ---------- | ------------- | --------------- |
| `/gtquest` | `gtquest.use` | 퀘스트 GUI 열기 |

## 관리자

모두 `gtquest.admin` 권한이 필요합니다.

**퀘스트**

| 명령어                     | 설명                                                         |
| -------------------------- | ------------------------------------------------------------ |
| `/gtquest create <이름>`   | 퀘스트 생성. 이름에 공백 가능                                |
| `/gtquest delete <id>`     | 퀘스트 삭제. 플레이어 진행 기록, 납품 목표, 보상도 함께 삭제 |
| `/gtquest list`            | 퀘스트 목록                                                  |
| `/gtquest info <id>`       | 퀘스트 정보                                                  |
| `/gtquest objectives <id>` | 납품 목표 편집 GUI (플레이어만)                              |
| `/gtquest rewards <id>`    | 보상 아이템 편집 GUI (플레이어만)                            |

**속성 (`set`)**

| 명령어                                       | 설명                       |
| -------------------------------------------- | -------------------------- |
| `/gtquest set <id> name <이름>`              | 이름                       |
| `/gtquest set <id> desc <설명>`              | 설명. `\n`은 줄바꿈        |
| `/gtquest set <id> prereq <선행id\|none>`    | 선행 퀘스트                |
| `/gtquest set <id> exp <경험치>`             | 보상 경험치 포인트         |
| `/gtquest set <id> money <금액>`             | 보상 돈. 소수 가능         |
| `/gtquest set <id> npc <npcId\|none>`        | Citizens NPC 연결          |
| `/gtquest set <id> material <아이템>`        | GUI 아이콘                 |
| `/gtquest set <id> hideobjectives <on\|off>` | 납품 목표 아이템 이름 숨김 |

**플레이어 관리**

| 명령어                                | 설명                                             |
| ------------------------------------- | ------------------------------------------------ |
| `/gtquest complete <플레이어> <id>`   | 강제 완료하고 보상 지급. 대상은 접속 중이어야 함 |
| `/gtquest reset <플레이어> <id\|all>` | 진행 기록 삭제. 오프라인 플레이어도 가능         |

## 주의 사항

- **`complete`는 조건을 확인하지 않습니다.** 수락하지 않았거나 이미 완료한 퀘스트여도 완료로 기록하고 보상을 다시
  줍니다. 납품 아이템도 가져가지 않습니다.
- **`reset`은 반복 퀘스트를 만드는 유일한 방법입니다.** 기록을 지우면 다시 "수락 가능" 상태가 됩니다.
- **`delete`는 되돌릴 수 없습니다.** 모든 플레이어의 해당 퀘스트 기록도 함께 지워집니다.
- `set npc`는 Citizens가 설치되어 있으면 존재하는 NPC ID인지 확인합니다. Citizens가 없으면 확인 없이 저장합니다.
- 설정을 다시 불러오는 명령어는 없습니다. `config.yml`을 바꾸면 서버를 재시작하세요.
