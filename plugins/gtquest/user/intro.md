# GTQuest

**아이템 납품형 퀘스트** 플러그인입니다. 플레이어는 GUI에서 퀘스트를 수락하고, 목표 아이템을 모아 납품하면 보상을
받습니다.

## 주요 기능

| 기능           | 설명                                                                               |
| -------------- | ---------------------------------------------------------------------------------- |
| 퀘스트 GUI     | `/퀘스트`로 목록을 열어 클릭으로 수락, 포기, 납품                                  |
| 납품 목표      | 여러 종류의 아이템을 목표로 지정. 이름, 인챈트, 커스텀 모델 데이터까지 같아야 인정 |
| 보상           | 아이템, 경험치, 돈(Vault)                                                          |
| 선행 퀘스트    | 다른 퀘스트를 완료해야 수락할 수 있게 연결                                         |
| NPC 연동       | Citizens NPC를 우클릭하면 그 NPC에 연결된 퀘스트만 표시                            |
| GUI 편집       | 납품 목표와 보상 아이템은 상자 GUI에 넣어서 설정                                   |
| PlaceholderAPI | `%gtquest_inprogress_count%`로 진행 중인 퀘스트 수 표시                            |

퀘스트는 한 번 완료하면 다시 할 수 없습니다. 반복 퀘스트가 필요하면 관리자가 `/gtquest reset`으로 기록을 지워야 합니다.
