# 게임 진행

모든 명령어는 `gthardcoreversus.admin` 권한이 필요합니다(기본값 OP). `/하드코어`로도 쓸 수 있습니다.

## 월드 세트

월드 세트 이름이 `gthcvs_a_1`이면 다음 세 월드가 한 세트입니다.

| 월드                 | 차원     |
| -------------------- | -------- |
| `gthcvs_a_1`         | 오버월드 |
| `gthcvs_a_1_nether`  | 네더     |
| `gthcvs_a_1_the_end` | 엔드     |

팀마다 처음 쓸 세트(`initial-world-set`)와 전멸했을 때 옮겨 갈 예비 세트(`reserve-world-sets`)를 정해 둡니다. 예비
세트를 다 쓰면 번호를 이어 붙여 자동으로 만듭니다(`gthcvs_a_3` 다음은 `gthcvs_a_4`).

## 1. 팀 배정

```
/gthardcoreversus setteam Steve A
/gthardcoreversus setteam Alex B
```

- 오프라인 플레이어도 미리 배정할 수 있습니다.
- 이미 배정된 플레이어에게 다시 실행하면 팀이 바뀝니다.
- 배정을 해제하는 명령어는 없습니다.

```
/gthardcoreversus info       # 두 팀 모두
/gthardcoreversus info A
```

팀원 목록은 접속 중이면 초록색, 아니면 회색으로 나오고, 즉사 횟수가 있으면 함께 나옵니다.

## 2. 시작

```
/gthardcoreversus start
```

1. 팀마다 월드 세트를 준비합니다. 이전 게임의 세트가 없으면 초기 세트를 씁니다. 월드가 없으면 새로 만듭니다.
2. 네더, 엔드 포털을 그 세트끼리 연결합니다.
3. **접속 중인 팀원**을 자기 팀 오버월드 스폰으로 보내고 서바이벌 모드로 바꿉니다.
4. 다음에 쓸 세트를 `prepare-ahead`개만큼 미리 만듭니다.
5. 시작 메시지와 규칙 안내(드래곤은 팀원이 함께 잡을 것)를 전체에 알립니다.

시작 전에는 사망, 전멸, 승리 판정을 하지 않습니다. 시작 후에 접속한 팀원은 자기 팀 월드가 아닌 곳에 있으면 자동으로 팀
월드 스폰으로 옮겨집니다.

## 3. 사망과 부활

팀에 배정된 플레이어가 죽으면:

1. 사망 화면 없이 바로 리스폰하고 **관전자**가 됩니다.
2. 액션바(또는 타이틀)에 남은 시간이 표시됩니다.
3. 시간이 지나면 리스폰 위치(침대나 리스폰 정박기, 없으면 팀 월드 스폰)로 옮겨져 서바이벌로 돌아옵니다.

- 대기 중에 접속을 끊어도 시간은 계속 흐릅니다. 다시 접속했을 때 이미 지났으면 바로 부활합니다.
- 서버를 재시작해도 이어집니다.
- 관전 중에는 핫바 관전 메뉴로 **같은 팀원에게만** 순간이동할 수 있습니다. 관전자의 자유 비행 범위는 제한하지 않습니다.
- 팀에 배정되지 않은 플레이어는 바닐라 규칙대로 죽고 살아납니다.

## 4. 전멸

**접속 중인 팀원이 모두 죽어 있거나 관전 대기 중이면** 전멸입니다. 오프라인 팀원은 세지 않습니다.

1. 팀원 전원의 부활 대기가 취소됩니다.
2. 팀의 전멸 횟수가 1 늘어납니다.
3. 다음 월드 세트로 옮깁니다. 접속 중인 팀원은 새 오버월드 스폰에서 서바이벌로 시작합니다.
4. 팀원 전원의 즉사 횟수가 0이 됩니다.
5. 이전 세트는 언로드합니다(삭제하지 않음).
6. 5초 뒤에 그다음 세트를 미리 만듭니다.

새 세트로 옮기면 인벤토리, 경험치 등은 그대로 따라갑니다. 초기화가 필요하면 Skript 등으로 처리하세요.

### 다음 세트를 불러오지 못한 경우

월드를 불러오지 못하면 팀은 **대기 상태**가 되고, 관리자에게 `wipe-no-reserve` 메시지가 갑니다. 다음 명령어로 직접
지정하면 바로 그 세트로 옮깁니다.

```
/gthardcoreversus setworld A gthcvs_a_10
```

대기 상태가 아닐 때 `setworld`를 쓰면 팀의 현재 세트 기록만 바꾸고 팀원을 옮기지는 않습니다.

## 5. 후원 즉사

```
/gthardcoreversus instakill Steve
```

- 대상을 즉사시키고, 대상의 **즉사 횟수**를 1 올립니다.
- 즉사로 죽어도 일반 사망과 똑같이 부활 대기를 거칩니다.
- **접속 중인 팀원 전원**의 즉사 횟수가 `instakill-wipe-stack`(기본 2) 이상이 되면 즉사 전멸 메시지와 함께 전멸
  처리합니다.
- 게임 시작 전이거나 팀이 없는 플레이어는 죽기만 하고 횟수는 오르지 않습니다.

후원 연동은 [GTDonation](/gtdonation/user/intro) 등에서 Skript로 이 명령어를 실행하거나 [API](../dev/api.md)를 호출해서
만듭니다.

## 6. 승리

어느 팀의 **현재 월드 세트**에서 엔더 드래곤이 죽으면 그 팀이 승리합니다.

- 먼저 잡은 한 팀만 승리로 처리합니다.
- 승리 메시지를 알리고 모두에게 타이틀을 띄웁니다. 게임을 멈추거나 서버를 끄지는 않습니다.
- "팀원 전원이 함께 잡기"는 규칙으로 안내만 하고, 실제로 인원을 확인하지는 않습니다.

## 7. 종료

```
/gthardcoreversus stop
```

1. 사망, 전멸, 승리 판정을 끕니다.
2. 이 플러그인이 쓰는 **모든 게임 월드를 삭제**합니다. 초기, 예비 세트와 자동으로 만든 세트(`gthcvs_a_4` 등)가 모두
   대상입니다.
3. 게임 월드 안에 있던 플레이어는 메인 월드 스폰으로 옮겨집니다.
4. 팀별 월드 세트 기록과 즉사 횟수를 비웁니다.

:::danger `stop`은 게임 월드를 **되돌릴 수 없게 삭제**합니다. 서버 기본 월드(`level-name`과 그 네더, 엔드)는 지우지
않습니다. :::

- 팀 배정, 사망 횟수, 누적 즉사 횟수, 전멸 횟수는 남습니다. 필요하면 `reset`으로 지우세요.
- 이미 관전 대기 중인 플레이어는 남은 타이머대로 부활합니다.
- 다시 `start`하면 초기 세트를 새로 만들어 처음부터 진행합니다.

## 기록 초기화

```
/gthardcoreversus reset Steve            # 전부
/gthardcoreversus reset Steve deaths     # 사망 횟수
/gthardcoreversus reset Steve instakills # 누적 즉사 횟수
/gthardcoreversus reset Steve stack      # 전멸 판정용 즉사 횟수
```

| 기록            | 설명                               | 자동 초기화                |
| --------------- | ---------------------------------- | -------------------------- |
| 사망 횟수       | 게임 시작 후 모든 사망 (즉사 포함) | 안 됨                      |
| 누적 즉사 횟수  | 즉사 받은 총 횟수                  | 안 됨                      |
| 즉사 횟수(스택) | 전멸 판정에 쓰는 횟수              | 새 월드 세트로 옮길 때     |
| 전멸 횟수       | 팀별. 새 세트로 옮긴 횟수          | 안 됨 (명령어로도 못 지움) |
