# GTHardcoreVersus

두 팀이 각자의 월드에서 **엔더 드래곤을 먼저 잡는** 하드코어 팀전 플러그인입니다. 방송 이벤트용으로 만들었으며, 후원으로
팀원을 즉사시키는 기능이 있습니다.

## 게임 규칙

| 규칙      | 설명                                                                                             |
| --------- | ------------------------------------------------------------------------------------------------ |
| 팀        | A팀, B팀 두 팀                                                                                   |
| 월드      | 팀마다 따로 쓰는 **월드 세트**(오버월드, 네더, 엔드)                                             |
| 사망      | 관전자가 되었다가 일정 시간(기본 30초) 뒤 부활                                                   |
| 전멸      | 접속 중인 팀원이 모두 죽어 있으면 전멸. 팀 전체가 **새 월드 세트**로 옮겨 처음부터 다시 시작     |
| 후원 즉사 | 후원이 들어오면 팀원을 즉사시킴. 접속 중인 팀원 전원의 즉사 횟수가 기준(기본 2) 이상이 되면 전멸 |
| 승리      | 자기 팀 월드 세트에서 엔더 드래곤을 먼저 잡은 팀                                                 |

## 주요 기능

| 기능                | 설명                                                            |
| ------------------- | --------------------------------------------------------------- |
| 월드 세트 자동 관리 | Multiverse로 월드를 미리 만들어 두고, 전멸하면 다음 세트로 교체 |
| 부활 타이머         | 접속을 끊거나 서버를 재시작해도 남은 시간이 이어짐              |
| 관전 제한           | 관전 중에는 같은 팀원에게만 순간이동 가능                       |
| 기록                | 플레이어별 사망 횟수, 즉사 횟수, 팀별 전멸 횟수                 |
| Skript 연동         | 즉사 처리와 기록 조회를 skript-reflect로 호출                   |
