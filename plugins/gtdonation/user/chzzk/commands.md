# 명령어

| 명령어 | 설명 | 권한 |
|---|---|---|
| `/chzzk unlink` | 치지직 계정 연동을 해제합니다 | 없음 (플레이어만 사용 가능) |

## /chzzk unlink

현재 세션을 끊고, 저장된 토큰을 삭제합니다.

| 상황 | 메시지 |
|---|---|
| 해제 성공 | `치지직 계정 연동이 해제되었습니다.` |
| 연동된 계정 없음 | `연동된 치지직 계정이 없습니다.` |
| 하위 명령 없이 입력 | `사용법: /chzzk unlink` |
| 콘솔에서 입력 | `플레이어만 사용할 수 있는 명령어입니다.` |

해제 후 서버에 다시 접속하면 로그인 링크가 다시 전송됩니다.
