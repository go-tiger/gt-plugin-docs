# OAuth 연동 흐름

GTDonation-Chzzk는 플레이어가 접속할 때 치지직 인증을 자동으로 처리합니다.

```
플레이어 접속
    │
    ▼
tokens.db에 UUID가 있는가?
    │
    ├─ 없음 ──▶ 로그인 링크 전송 ──▶ 치지직 로그인 ──▶ 콜백 수신 ──▶ 토큰 저장 ──▶ 세션 연결
    │
    └─ 있음 ──▶ 마지막 갱신 후 29일 초과?
                  ├─ 예 ───▶ 재인증 링크 전송
                  └─ 아니오 ▶ 토큰 갱신 ──┬─ 성공 ─▶ 세션 연결
                                          └─ 실패 ─▶ 재인증 링크 전송
```

## 최초 로그인

처음 접속한 플레이어에게 클릭 가능한 링크가 전송됩니다.

```
[CHZZK] 로그인 링크를 클릭하세요: 여기를 클릭
```

링크는 치지직 계정 연동 페이지로 이동하며, 플레이어 UUID가 `state` 값으로 함께 전달됩니다. 로그인 후 치지직이 Redirect URI로 콜백을 보내면, 플러그인의 내장 HTTP 서버가 토큰을 발급받아 저장합니다.

브라우저에는 결과가 표시됩니다.

| 화면 | 의미 |
|---|---|
| 인증이 완료되었습니다. | 성공 |
| 인증 실패 | 토큰 발급 실패 (Client Secret, Redirect URI 확인) |
| 잘못된 state | 이미 처리됐거나 만료된 링크. 서버에 다시 접속해 새 링크를 받으세요 |

## 자동 재연결

다음 접속부터는 저장된 토큰을 갱신해서 바로 연결합니다. 연결되면 다음 메시지가 나옵니다.

```
[CHZZK] 인증이 완료되었습니다.
```

다음 경우에는 재인증 링크가 전송됩니다.

- 마지막 토큰 갱신 후 **29일이 지난** 경우
- 토큰 갱신에 실패한 경우 (치지직에서 연동을 해제한 경우 등)

```
[CHZZK] 인증이 만료되었습니다. 다시 인증하려면 클릭하세요.
```

## 세션 연결 실패

세션 생성에 실패하면 2초 뒤 한 번 다시 시도합니다. 그래도 실패하면 다음 메시지가 나오며, 서버에 다시 접속하면 처음부터 재시도합니다.

```
[CHZZK] 세션 생성 중 오류가 발생했습니다.
```

## 연결 해제

- 플레이어가 서버에서 나가면 세션이 종료됩니다. 토큰은 유지되어 다음 접속 때 자동으로 연결됩니다.
- 연동 자체를 끊으려면 [`/chzzk unlink`](./commands.md)를 사용합니다.
